# 業務知識の見本（抜粋）

この見本は、業務知識の資料で一つの事実の置き場に迷いやすい箇所だけを、図書館の貸出を題材に抜き出したものである。図書館の貸出は、状態が一生を持つ業務である。計算が中心の業務、期限つきの義務が続く業務、読み取りが中心の業務、定義や設定の業務の見本は、[business-knowledge.examples/](business-knowledge.examples/) にある。補足の NOTE は、薬局の窓口会計を題材に示す。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 「5冊まで」は、範囲、数え方、できないことの三つに分けた

「借りられるのは5冊まで」という一文には、いつでも成り立つ範囲、冊数の数え方、上限のときに貸そうとした結果が混ざっている。範囲は制約に、数え方は計算に置き、上限にある在り方に状況の名前を付けて、できないことは表の行にした。状況も行も、範囲と数え方を名前で指すだけで、5冊という値を書き直さない。値を変えるときに直す所が制約の一か所で済む。

```markdown
## 制約

### 貸出上限

一人の利用者が借りている冊数は、5冊以下である。破れると、一人が本を抱え込み、ほかの利用者が借りられなくなる。

## 状況

### 貸出上限に達している利用者

借りている冊数が、貸出上限の許す最大に等しい利用者。

## 計算

### 借りている冊数

その利用者の貸出のうち、数える時点で貸出中か延滞のものの数。返却済みの貸出は数えない。

## 行動・出来事と判断

| いつ | 誰が | 何をすると | 何が起きる | どの決まりによるか |
|---|---|---|---|---|
| 貸出上限に達している利用者 | 窓口の職員 | 本を貸す | できない。何も変わらない | 貸出上限、借りている冊数 |
```

## 返却期限は、日の区分を先に決めてから求めた

返却期限は「貸した日の14日後」だけでは決まらない。その日が休館日なら返せないからである。そこで、日が開館日か休館日かを決める計算を先に置き、返却期限の計算はその区分を名前で使った。開館日か休館日かは、きっかけで移り変わらず、開館カレンダーから導かれるので、状況ではなく計算である。

どの時点の開館カレンダーを使うかも書いた。書かないと、貸した後に臨時の休館が決まったとき、期限が動くのかが決まらない。

```markdown
## 前提

### 開館カレンダー

どの日に開館するかは、施設運営の業務が決める。この業務は、日ごとの開館の有無を読むだけである。

## 計算

### 日の区分

開館カレンダーで開館する日を開館日、それ以外の日を休館日とする。

### 返却期限

貸した日の14日後の日とする。その日が休館日なら、それより後で最も早い開館日とする。日の区分には、貸した時点の開館カレンダーを使う。貸した後に開館カレンダーが変わっても、返却期限は変えない。
```

## 前提の事実で答えが変わる所は、組み合わせに名前を付けて状況にした

貸出を延長できるかは、貸出が貸出中であることだけでは決まらず、その本にほかの利用者の予約があるかで変わる。予約は予約の業務が決めるので、この業務には前提である。「貸出中で、予約が無ければ延長できる」と条件の文で書く代わりに、自分の状態と前提の事実の組み合わせを二つの状況にした。条件は表の行に吸収され、どちらの行も根拠は前提の名前で足りる。

```markdown
## 前提

### 本の予約

ほかの利用者がその本の順番を待っているかは、予約の業務が決める。この業務は、きっかけが来た時点の予約の有無を読むだけである。

## 状況

### 貸出中（OnLoan）

本が利用者の手元にあり、返却期限をまだ過ぎていない貸出。その本に、ほかの利用者の本の予約が無い。

### 予約のある貸出中（OnLoanReserved）

本が利用者の手元にあり、返却期限をまだ過ぎていない貸出。その本に、ほかの利用者の本の予約がある。

## 行動・出来事と判断

| いつ | 誰が | 何をすると | 何が起きる | どの決まりによるか |
|---|---|---|---|---|
| 貸出中 | 借りた本人 | 貸出を延長する | 貸出中のまま、「貸出を延長した（LoanExtended）」が起きる | 本の予約 |
| 予約のある貸出中 | 借りた本人 | 貸出を延長する | できない。何も変わらない | 本の予約 |
```

## 誰が行うかで答えが変わる所は、行を分けた

同じ状況の同じきっかけでも、借りた本人が延長するのと、本人でない人が延長するのとでは答えが違うので、別の行にした。誰が行えるかという決まりは制約に名前を立て、行はそれを指す。時刻が来て起きることは、アプリが起こす行として同じ表に置いた。延滞にするかを人は選ばず、返却期限という事実だけで決まるからである。所有者ひとりが使う道具なら、他人は業務に登場しないので、本人でない人の行は作らない。

```markdown
## 制約

### 貸出を変えるのは借りた本人

延長と返却は、その貸出を借りた本人の意思だけで行われる。破れると、本人の知らないうちに返す日が変わり、延滞の責任を本人に問えなくなる。

## 行動・出来事と判断

| いつ | 誰が | 何をすると | 何が起きる | どの決まりによるか |
|---|---|---|---|---|
| 貸出中、予約のある貸出中 | 借りた本人でない人 | 貸出を延長する | できない。何も変わらない | 貸出を変えるのは借りた本人 |
| 貸出中、予約のある貸出中 | アプリ | 返却期限の翌日になる | 延滞になり、「延滞にした（MarkedOverdue）」が起きる | 返却期限 |
```

## 拒否の BDD の NOTE は、行の「どの決まりによるか」にある名前にした

拒否の BDD は、表のできない行を具体の値で示す。`NOTE: Rule:` には、その行の「どの決まりによるか」にある制約、前提、状況の名前をそのまま書いた。返却済みの貸出を返そうとする行のように、範囲もほかの業務の事実も関わらず、その状況がそのきっかけを受けないだけなら、どの決まりによるかは状況の名前（返却済み）で足りる。根拠に計算も並ぶ行（貸出上限、借りている冊数）では、制約の名前を選ぶ。計算は値を求めるだけで、拒む決まりではないからである。`Reason:` には決まりの写しではなく、この場面の値でなぜできないかを書いた。同時に借りて負けた側も、利用者から見れば同じ拒否なので、同じ名前を指す。

````markdown
### [BDD-003] 5冊借りている利用者は、6冊目を借りられない

```gherkin
Given: 利用者 U-0001 は本 B-1001〜B-1005 の5冊を借りていて、どれも貸出中である
When: 窓口の職員が2026年10月1日に、利用者 U-0001 へ本 B-1006 を貸す
Then: 借りられず、貸出は生まれない
  NOTE: Rule: 貸出上限
    Reason: 借りている冊数がすでに5冊で、貸すと6冊になる
```

### [BDD-009] ほかの利用者が予約している本の貸出は、延長できない

```gherkin
Given: 利用者 U-0001 は本 B-1001 を借りていて、返却期限は2026年10月15日である
  And: 利用者 U-0002 が本 B-1001 を予約している
When: 利用者 U-0001 が2026年10月10日に、本 B-1001 の貸出を延長する
Then: 延長できず、返却期限は2026年10月15日のままである
  NOTE: Rule: 本の予約
    Reason: 利用者 U-0002 が本 B-1001 の順番を待っている
```
````

## 窓口会計の結果は金額と内訳まで書き、選定療養費の背景は NOTE で補った

会計時に誰がいくら受け取るか、どの金額が仕訳のどの内訳になるかは BDD の本文で分かる。初めて読む人が選定療養費の意味と例示値の扱いを理解できるように、NOTE を添えた。

### [BDD-103] 窓口で全額を受け取ると選定療養費と消費税が別々に計上される

```gherkin
Given: 調剤後の窓口会計で、調剤報酬3,500円のうち保険請求分は2,450円、患者の窓口負担分は1,050円である
  And: 調剤報酬は350点で、そのうち薬剤料は151点である
  And: 患者が支払う選定療養費は税抜1,000円、消費税は100円である
When: 会計担当者が薬局の窓口で患者から現金2,150円を受け取り、会計を確定する
Then: 借方に保険請求分の売掛金2,450円と現金2,150円が計上される
  And: 貸方に調剤売上の技術料収入1,990円と薬剤料収入1,510円、税抜の選定療養費1,000円、消費税100円がそれぞれ計上される
  And: 患者の窓口未収金は生じない
  NOTE: この例での選定療養費は、患者が後発医薬品のある先発医薬品を希望して選んだときの追加負担を指す。税抜1,000円と消費税100円は、会計時の内訳を説明するための例示値である。
```
