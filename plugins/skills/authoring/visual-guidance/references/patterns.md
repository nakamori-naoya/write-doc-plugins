# 目的別の図の選択表

**図は見た目ではなく、読み手が答えを得たい問いで選ぶ。** 1枚で複数の問いに答えようとせず、主要な問いを1つに絞る。

| 読み手の問い | 選ぶ型 | 空間へ写す意味 | 選ばない型 |
|---|---|---|---|
| 何があり、どこに属し、どう接続するか | 構成図・地図 | 位置＝所属や配置、領域＝境界、線＝接続 | 実行順を示すシーケンス |
| 誰が誰と、どの順でやり取りするか | シーケンス図 | 横位置＝主体、縦軸＝時間、矢印＝メッセージ | 静的な構成図 |
| どの条件で状態が変わるか | 状態遷移図 | ノード＝状態、線＝遷移、ラベル＝条件 | 単なる時系列 |
| どの条件で経路が分かれるか | 制御フロー | 分岐点＝判断、線＝到達経路 | 一本道のフロー図 |
| 値はどこで生まれ、変換され、確定するか | データフロー | 線＝データ、合流＝集約、終点＝確定 | 呼び出し順だけのシーケンス |
| 何に依存し、変更がどこへ波及するか | 依存関係図・層図 | 位置＝層、矢印＝依存方向、色＝違反や変更 | 全要素のクラス図 |
| 選択肢は何が違うか | 比較図 | 同じ位置＝比較軸、色＝差分 | 項目数が少ない場合の飾り図 |
| 何がどの範囲に含まれるか | 包含図・境界図 | 入れ子＝包含、背景領域＝責務や所有 | 順序を示すフロー図 |
| 何がどの親の下にあり、階層はどう分かれるか | ツリー | 深さ＝階層、枝＝親子関係 | 所有境界が主題の包含図 |
| データ同士がどのキーで関係するか | ER・データモデル図 | ノード＝実体、線＝関係、記号＝多重度 | 実行順のデータフロー |
| 2つの軸でどこに分類・優先付けされるか | 2軸マトリクス | 横軸・縦軸＝評価軸、位置＝分類 | 時系列や処理順の図 |
| 利用者がどの画面をどう移動するか | 画面遷移・ユーザーフロー | ノード＝画面、線＝操作と遷移 | APIのシーケンス図 |
| いつ何が起きるか | タイムライン | 一方向の軸＝時間、間隔＝期間 | 状態遷移図 |
| 変更前後で何が変わったか | before / after | 同じ配置＝比較可能性、色＝変化点 | 別配置の2枚の図 |
| 量・割合・傾向はどう違うか | 棒・線・散布・積み上げ | 長さ・位置・面積＝数値 | 数値を面積へ正しく写せない装飾 |
| どこが重要で、どこへ視線を向けるか | 注釈付き画像 | 元画像＝対象、吹き出し＝注目点 | 対象を再現した箱図 |

## 選択の優先順位

1. 問いに直接答える型を選ぶ。
2. 同じ問いに複数候補があれば、読み手が既に知っている表現を選ぶ。
3. 図より表や番号付き手順の方が正確なら図を選ばない。
4. 1枚が複雑なら、問いを分けて複数枚にする。

## 混同しやすい型の決め手

- **構成図 / 依存関係図:** 配置・接続・所有境界が主題なら構成図。変更したときに何が壊れ、どこへ波及するかが主題なら依存関係図。
- **制御フロー / データフロー:** 分岐条件と到達経路が主題なら制御フロー。値の生成・変換・合流・確定が主題ならデータフロー。
- **シーケンス図 / データフロー:** 主体間のメッセージ順が主題ならシーケンス図。値そのものの変化が主題ならデータフロー。
- **状態遷移図 / タイムライン:** 条件で行き来できる状態が主題なら状態遷移図。実際に起きた出来事の時刻や期間が主題ならタイムライン。

## 図にしないもの

- 分岐のない一本道。番号付き手順で足りる。
- 要素が2つしかなく、差が1項目しかない比較。短文で足りる。
- 文章を箱へコピーして矢印で結んだもの。
- 本文の主要な主張と関係しないイメージ画像。
