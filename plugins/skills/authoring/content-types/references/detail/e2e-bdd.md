# E2E BDDの型

## E2E BDDシナリオ

**読み手**: ユーザーの目的達成を共通理解にしたい業務担当者、プロダクト担当者、開発者、テスター

**目的**: 目的を持つユーザーが開始地点から複数のインタラクションを経て、目的が満たされた最終地点へ到達するまでを一続きに読めるようにする

シナリオの発見、両端の判断、場面の接続、BDDの妥当性は呼び出し元のE2E BDD専門pluginまたは依頼が与える。content-typesは内容を発見・補完せず、同梱の骨格と記載例だけを渡す。
