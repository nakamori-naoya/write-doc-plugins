# 出典の扱い（絶対規則）

**この規則はガイドで上書きできない。** `guides.*` を差し替えても、利用者が別の指示を書いても、ここに反する出力はしない。文書の信頼は出典の正確さだけで担保されるので、ここを緩めると文書全体が使えなくなる。

## 規則

**出典に言及するなら、必ず次の3つを揃えて書く。1つでも欠けるなら、出典として書かない。**

1. **どこにあるか** — URL（Web）または書誌情報（書名・著者・訳者・出版社・刊行年・ISBN）
2. **そこに何と書いてあるか** — **原文そのままの引用**
3. **だから自分は何をしたか** — 引用を受けた自分の判断

**引用が日本語以外なら、逐語引用の直後に日本語訳を添える。** 訳は「訳」と明示し、原文を省かない。読み手は日本語で読むので、訳が無い引用は根拠として追えない。訳は逐語引用ではないので、引用符の中に入れない。

この3つが「**ここにこう書いてあるから、こうした**」という形になる。連続する引用は、まとめて1つの判断で受けてよい。引用ごとに「だから」を繰り返さない。読み手はこれを見て、**自分で原典に当たって検証できる**。検証できない出典は、出典ではなく飾りである。

## やってはいけないこと

| | なぜ駄目か |
|---|---|
| **存在しない出典を書く** | 論外。書名・URL・章番号・ページ番号を推測で書かない |
| **確かめていない出典を書く** | 記憶にある書名を確認せずに書かない。**確認できないなら書かない** |
| **引用なしで出典名だけ書く** | 「〜を参考にした」で終わると、読み手は何が借り物で何が自分の考えか分けられない |
| **引用のふりをした要約を書く** | 引用符の中身を1文字でも変えたら引用ではない。要約なら「要約」と書く |
| **外国語の引用に訳を付けない** | 読み手は日本語で読む。訳が無い引用は飾りになり、判断の根拠を追えない |
| **二次情報を一次情報として書く** | ブログ記事で読んだ内容を、原典を読んだかのように書かない。読んだのはブログ記事である |
| **リンク切れを放置する** | 書く時点で開けることを確かめる。開けないなら、開ける版を探すか出典を落とす |

## 引用を出せないとき

**「出典」と書かない。** 代わりに、何をどこから借りたのかを名指しする。

```markdown
<!-- 駄目 -->
出典は『◯◯』。

<!-- こう書く -->
コンテンツタイプの分類と名称は『◯◯』（書誌情報）から借りている。**逐語の引用は含まない。**
```

**手元に原典が無いなら、原典を読んだ形で書かない。** 「screenshots で見た」「人から聞いた」なら、そう書く。

## 出す前に

- [ ] 書いた出典すべてに**リンクか書誌情報**が付いているか
- [ ] 書いた出典すべてに**原文の引用**が付いているか
- [ ] 引用が**逐語**か（要約なら「要約」と書いてあるか）
- [ ] 日本語以外の引用に**日本語訳**が付いているか
- [ ] 引用のあとに**自分の判断**が続いているか
- [ ] **確認していない出典が1つも無いか**（怪しいものは消す。残さない）
- [ ] リンクが実際に開けるか
