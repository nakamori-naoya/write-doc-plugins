# 観測値の扱いガイド（既定）

`citation` は他人の文献を、この規律は**自分が観測・計測・推定した値**を扱う。

## 実測と推定を分ける

実測値には、試行回数・環境・集計方法を添える。
推定値には「推定」と幅を書く。推定を根拠に結論を出すなら、精度も示す。
観測範囲の扱いは `section` の「理解の飛躍に合う説明を選ぶ」に従う。

## 表は条件ごとに分け、同じ条件の中でだけ比べる

**取得条件が同じ値どうしを比較する。** 環境・対象の量・開始時の状態を揃える。
条件が違うなら表を分け、「この表の中でだけ比較できる」と明記する。
条件が変わると順位が逆転しうるため、混ぜると判断に必要な違いが消える。

架空の予約受付の比較なら、受付人数が少ない場合と多い場合を別の表にする。
各表では受付人数と開始時の状態を揃え、受付方法どうしを比較する。

## 負けている数字と空欄に意味を書く

期待と逆のケース、失敗した回、外れ値を落とさない。
中央値だけで済ませず、最大値やp95（値の95%が収まる上限）でばらつきも示す。
推奨案が負けている条件を書き、それでも採る理由を述べる。
主張の隣への置き方は `structure` の「本文に残す情報を選ぶ」に従う。

**空欄・「—」・「N/A」・「0」の意味は言葉で示す。** 該当なし、未計測、本当にゼロを区別する。
記号は「該当なし」「未計測」のような言葉へ置き換える。
架空の予約受付表なら「失敗0回」と書けば、測っていない状態と区別できる。

## 未計測は「何をすれば決まるか」まで

未確認の扱いは `style`、主張の隣への配置は `structure` に従う。
未計測・未検証の項目には、何を測る・確かめると判断できるかまで書く。

## 出す前に

- [ ] 実測に条件があり、推定に「推定」と幅があるか。結論の根拠にした推定には精度もあるか
- [ ] 表を条件ごとに分け、比較できる範囲を明記したか
- [ ] 失敗した回・外れ値・ばらつきと、推奨案が負けている条件・それでも採る理由を残したか
- [ ] 空欄・記号・ゼロの意味が言葉で分かるか
- [ ] 未計測・未検証の項目に、何をすれば判断できるかを書いたか
