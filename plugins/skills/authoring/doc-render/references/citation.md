# 出典を媒体へ写す

**3点セット（リンク・原文の引用・自分の判断）を揃えるかは、書く側の規律が決める。** ここは書式だけ。

## 書き方

### Markdown

````markdown
[中野芳樹「客観的速読のための現代文読解法一覧」](https://example.com/dokkaiho.pdf) は R1 をこう定める。

> 具体例・比喩・引用（「たとえば」「〜のような」…で導かれる範囲、引用符内）は
> **要点としない**。その直前または直後にある抽象論を要点とする

**だから本ガイドは「例そのものには線を引かない」を規則にしている。**
書く側から見ると、これは「例の前後に抽象論を必ず置く」という執筆規則になる。
````

引用ブロックのあと、**必ず自分の判断を続ける**。引用で段落を終えない。

### HTML

```html
<blockquote>
  <p>具体例・比喩・引用（…）は<strong>要点としない</strong>。その直前または直後にある抽象論を要点とする</p>
  <span class="attribution">
    — 中野芳樹「客観的速読のための現代文読解法一覧」
    <a href="https://example.com/dokkaiho.pdf">（PDF）</a>
  </span>
</blockquote>
<p><mark>だから本ガイドは「例そのものには線を引かない」を規則にしている。</mark></p>
```

### 引用の量

**必要最小限にする。** 判断の根拠になる箇所だけを引く。章まるごとの転載はしない。著作物なら、引用が主で自分の文が従になる構成は避ける。
