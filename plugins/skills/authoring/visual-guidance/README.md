# visual-guidance

**何を、どの図で伝えるかを決める。** 境界・レーン・凡例を固定配置する資料図では、参考画像を使った画像生成が適するかも判断する。文章の規律やHTML/SVGの描画方法は持たない。

## 使う

```text
/choose-visual
```

依頼・本文・素材から読み手、目的、主要な主張を取り、図の主張・図の型・図の内容と挿入位置を返す。画像生成を選んだ場合は、同梱の参考画像と生成後の照合項目も指定する。

## 判断すること

- 図にする価値がある主要な主張はどれか
- 読み手が答えを得たい問いは何か
- 構成図、依存関係図、シーケンス図、状態遷移図などのどれが合うか
- コードネイティブな図で足りるか、固定レイアウトの画像生成が必要か
- 位置、形、線、色へ何の意味を持たせるか

## 判断しないこと

- 文章の構成・文体・強調
- HTML、SVG、Markdownなど媒体ごとの描画方法
- 資料全体で図を必須にするかという設定
- 図が無い結果を呼び出し元が許すかという判定
