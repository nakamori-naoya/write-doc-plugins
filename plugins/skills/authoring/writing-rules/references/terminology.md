# 用語の扱い（絶対規則）

**この規則はガイドで上書きできない。** 読み手が語の意味を取れなければ、その文は情報を運んでいない。書き手にとって自明な語ほど、この検査を飛ばしやすい。

対象は本文・見出し・図・表・コード注釈・箇条書きのすべてである。差し替えたい場合も、この規則より緩い規律は採用しない。

## 二つの禁止

1. **実在しない語を作って、実在するかのように使わない。**
2. **実在しても読み手に通じない語を、通じる前提で使わない。**

どちらも症状は同じである。読み手は語を調べに行き、見つからないか、見つかっても文脈と合わない説明に当たり、そこで読むのをやめる。

## 語ごとの判定手順

本文に出す名詞・動詞句のうち、**日常語でないものすべて**に、上から順に適用する。

### 1. その語は実在するか

**出典を1つ挙げられるか**で判定する。規格、公式資料、辞書、広く参照される書籍のいずれかに、**その意味で**載っていること。

- 挙げられない → **その語は使わない。** 手順4へ進む。
- 「聞いたことがある」「たぶん一般的」は挙げられないと同じである。**記憶を根拠にしない。**
- 語は実在するが自分が使おうとしている意味では載っていない場合も、挙げられないものとして扱う。

### 2. この読み手に、説明なしで通じるか

**読み手が普段読み書きしている資料に、その語が出るか**で判定する。読み手が誰かは`reader_context`にある。

- 出る → そのまま使ってよい。手順5へ。
- 出ない、または分からない → **通じないものとして扱う。** 手順3へ。
- **「エンジニア向けだから通じる」と判定しない。** 分野が違えば通じない。同じ分野でも、特定のフレームワーク・特定の学術領域・特定の社内文化でしか使わない語は通じない。

### 3. 語を出さずに済ませられるか

**まず、具体的な動作・状態・数値へ言い換えて試す。** 言い換えで文が成立するなら、**その語は出さない。**

語を出す必要があるのは次の2つだけである。

- **照合が必要な固有名**（API名、コード中の名前、コマンド、画面のラベル、エラーコード、正式な製品名）。表記を変えずに載せ、必要な説明を添える。
- **その語自体が、この先の会話や他の文書で共通語になるもの**。この場合は初出で「この文書で何を指すか」を書いてから使う。語の全意味を定義する必要はない。

**略語を正式名称へ展開しただけでは説明にならない。** 何をするものかを書く。

### 4. どうしても名前が要るとき

既存の語で言えることに新しい名前を付けない。それでも名前が必要なら、**作ったことを明示してから使う。**

```markdown
<!-- 駄目 -->
繰上げ待機状態の予約は、次の繰上げ対象から除外する。

<!-- こう書く -->
確定予約が取り消されるまで待っている予約待ちを、この文書では「繰上げ待ち」と呼ぶ。繰上げ待ちは、次の繰上げ対象から除外する。
```

- 宣言のない造語は禁止である。
- 宣言した語も、**他の文書や会話で通じる語ではない**。この文書の外へ持ち出す前提で書かない。
- 同じ概念に、文書ごとに違う名前を付けない。すでに名前があるなら、そちらを使う。

### 5. 一度決めた呼び名を変えない

同じ概念は同じ呼び名で最後まで追えるようにする。説明の途中で日本語・英語・略語を断りなく切り替えない。用語集がある場合も、**その語が理解に必要になる場所で意味が分かるようにする。** 用語集だけへ説明を追い出さない。

## やってはいけないこと

| | なぜ駄目か |
|---|---|
| **出典を確かめずに専門用語を使う** | その語が実在しない、または別の意味だった場合、読み手は誤った理解のまま先へ進む |
| **宣言なしで造語する** | 読み手は既存の語だと思って調べ、見つからずに止まる |
| **難しい英語を難しい日本語へ置き換える** | 「当該機構の責務」は「the responsibility of the mechanism」と同じだけ通じない |
| **直訳カタカナで済ませる** | 音を写しただけで、何をするものかは伝わっていない |
| **社内・特定コミュニティの語を一般語として使う** | 読み手が変わった瞬間に通じなくなる。異動・退職・外部公開で必ず起きる |
| **初出で説明した語を、別の呼び方へ変える** | 読み手は別のものだと読む |
| **用語集へのリンクで説明を代替する** | 判断に必要な語の意味を、読み手に別ページを開かせて取りに行かせている |

## 書き終えた後の検査

本文に出る日常語でない語を並べ、次のどれかに当たることを1語ずつ確かめる。

- 出典を挙げられ、かつ読み手が普段読む資料に出る語である
- 照合が必要な固有名として、説明を添えて載せている
- 初出で「この文書で何を指すか」を書いてから使っている
- 「この文書では〜と呼ぶ」と宣言した語である

**どれにも当たらない語が1つでもあれば、言い換えるか、説明を足すか、宣言を足す。** 数を数えることが目的ではなく、1語ずつ根拠を言えることが合格条件である。

平易な言い換えの具体例と語り口の規約は[style](style.md)にある。外部資料から借りた語の出典の書き方は[citation](citation.md)に従う。
