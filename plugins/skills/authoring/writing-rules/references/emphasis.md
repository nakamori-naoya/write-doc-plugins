# 強調ガイド（既定）

**書いた文章をどう目立たせるか**の規約。差し替えたい場合は `.harness-plugins/writing-rules.config.yml` の `rules.emphasis` に自分のファイルを指す。

`structure` が並べ方、`section` が書き方を決める。**このガイドが決めるのは、どの役をどこへ当てるか**である。

**その役が HTML や Markdown でどう出るかは、ここでは決めない。** 媒体表現は、資料を出す側が持つ。ここで書式まで決めると、媒体が増えるたびに文章の規律を書き換えることになる。

## 目立たせる手段

手段は4つだけ。増やさない。**手段が増えるほど、どれも目立たなくなる。**

| 役 | 何を浮かせるか |
|---|---|
| **要点** | その段落の主張 |
| **キーワード** | 中心概念の語（初出だけ） |
| **一言でいうと** | 文書全体の主張（1文書に1つ） |
| **要約項目** | 冒頭要約の項目 |

**この4つの役の名前が、媒体側との契約である。** 何のタグ・記号に写すかは媒体側が決める。

**この4つ以外の目的で強調を使わない。** 装飾で使った瞬間、読み手は強調を信用しなくなる。

## 合否の基準はひとつ

**引いた箇所だけを拾い読みして、文書の筋が通ること。** これだけを見る。

ここから2つ出る。

- **迷ったら引かない。** 強調が少ないことは誤りではない。拾い読みが成立していれば足りている。
- **引くものが見つからない段落は、主張が無い段落である。** 引くものを探すのではなく、段落を削るか書き直す。

**比率は測らない。** 原典には上限がある。

> 1段落内の要点が、その段落全体の**50%を超えてはならない**。超えた場合は重要度の低い規則（R7・R12）から外す

**これは採らない。** 原典は「他人が書いた文章へ後から線を引く」場面の規則で、引きすぎを防ぐためにある。**自分が書いた文章に当てると、主張の濃い段落ほど引けなくなる**という逆向きの圧になる。比率ではなく、拾い読みが成立するかだけを見る。

## どこへ当てるか

下敷きは[中野芳樹「客観的速読のための現代文読解法一覧」](https://nakanogendaibun.com/wp-content/uploads/2026/05/9db385ece6cb4b91d836bafc7ba5a03a.pdf)の読解規則（R1〜R12）。`section` ガイドの表と番号が対応する。**あちらが「こう書く」、こちらが「だからここへ当てる」。**

**引かない側を明示してある規則が多い。** 強調の失敗は引き足りないことより、**引いてはいけない場所へ引くこと**で起きる。

| | 場面 | 当てるのは | 当てないのは |
|---|---|---|---|
| **R1** | 具体例・比喩・引用 | 例の**直前か直後の抽象論** | **具体例そのもの**、引用符の中 |
| **R2** | 否定・比較（「AではなくB」） | **肯定側の B だけ** | 否定側の A |
| **R3** | 対比・対照 | **主題側の項だけ** | 従属側。主題が判別できない同等対比は**両方** |
| **R4** | 修辞疑問 | 問いと、対応する答え | 答えが特定できないときの答え側 |
| **R5** | 譲歩（「たしかに A」） | **逆接以降の本音 B** | 譲歩節そのもの |
| **R6** | 要約表現（「つまり」） | **後件** | 前件 |
| **R7** | 重視・強調（「重要」「本質」） | その節の要点 | 「重要である」という語だけの部分 |
| **R8** | 筆者の主観（「〜べきだ」） | その判断 | — |
| **R10** | 逆接（「しかし」） | 段落冒頭、または文書中で**最初に現れた逆接**の後件だけ | **それ以外の逆接すべて** |
| **R11** | 定義・命名 | 定義文を要点、**定義される語をキーワード** | — |
| **R12** | 要点並列（「第一に」） | 各要点 | 並列を示す語（「第一に」自体） |

**R9（反語）は欠番。** 原典は反語をこう定める。

> R9 | 反語（「〜ではないだろうか」「〜といえないだろうか」） | 要点とする

**だが本ガイドは採らない。** テクニカルライティングで反語は使わないためで、`section` ガイドで書き方ごと落としてある。番号は原典と対応させるため欠番のままにしてある。

キーワードマーカーにしてよいのは次の3つだけ。**初出の1回、1文書 5〜10語まで。**

1. **R11 で定義・命名した当の語**（定義文全体は要点、定義される語だけをキーワード）
2. 独自の意味を与えて**繰り返し使う中心概念**
3. **対比の軸になる一対の語**（例: 線形／非線形）

## 当てる範囲

- 単位は文全体ではなく、**述部を含む最小の節**。主語が別の節にあるときだけ主語を含める。
- 修飾語は、**外すと要点の意味が変わるときだけ**含める。
- 同じ文で複数の規則が当たり、範囲が隣接・重複するなら、**1つの連続した範囲に統合する**。細切れに引かない。
- 同じ内容が反復されているなら、**最初の1箇所だけ**。

## 当て終わったら

- [ ] **強調だけを拾い読みして、文書の筋が通るか**（これが唯一の合否基準）
- [ ] 役が4つに収まっているか（装飾目的の強調が無いか）
- [ ] 具体例（R1）そのものを引いていないか
- [ ] 否定側（R2 の A）・譲歩節（R5 の A）を引いていないか
- [ ] 逆接（R10）を2回以上引いていないか
- [ ] キーワードが3条件のいずれかに該当し、初出だけになっているか
- [ ] 引くものが無い段落を、引くために無理に引いていないか
