# コード注釈を媒体へ写す

入力で確定したコードの役と境界を媒体表現へ変換する。掲載範囲、注釈内容、読ませる層と参照させる層、段階、省略箇所は判断しない。行番号は生成しない。入力された注釈の位置と書式を変えずに写す。

| 受け取る役 | Markdown |
|---|---|
| 読ませるコード | 本文の fenced code block |
| 参照させるコード | 付録見出し下の fenced code block |
| 注釈 | `▼` で始まる行を、該当行の直前に置く |
| 空行 | 空行 |
| 省略の印 | `…` と原典リンク |
| 段階 | 見出し |
| 段階の入出力 | 箇条書き |
| 次の段階への導線 | 相対リンク |

````markdown
`path/to/file`（[原典](https://example.com/repo/blob/<commit>/path/to/file)）

```text
▼［新規］受け取った注釈
code
```
````

元のコードコメントと注釈を区別するため、注釈行の先頭へ `▼` を付ける。
