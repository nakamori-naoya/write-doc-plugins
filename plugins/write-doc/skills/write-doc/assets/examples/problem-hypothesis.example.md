# 課題と価値仮説の見本（抜粋）

この見本は、課題と価値仮説の資料で判断が分かれやすい箇所だけを、少年サッカークラブの当番の題材から抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 課題は、望みではなく直近の出来事で書く

依頼は「当番表のアプリを作りたい」だった。この題材では、アプリが欲しいかではなく、直近の一回で誰が何に困り、その場でどうしのいだかを書いた。しのぐために手間を払っていれば課題は実在する。本人から聞けていない困りごとは、出来事ではなく仮説として分けて書く。

> 9月6日の練習試合の前日、配車当番の2家庭から、夜9時を過ぎて出られないと連絡があった。担当者はほかの保護者へ個別に電話とLINEで頼み、夜11時過ぎに1家庭の代わりが決まった。もう1台は決まらず、当日はコーチが自分の車で2往復した。（出典：事務局の担当者の発言、観測時点：2026-09-12）
>
> 事務局の担当者は、共働きの保護者から「代わりを探すのがいちばんしんどい」と聞いたことがあると話した。保護者本人からは聞けていないので、これは仮説として扱う。

## 本質は、より多くの症状を説明する原因を選び、割れたら残す

当番表の見にくさは、前夜の依頼と当日の欠けを説明できないので退けた。当番の回数が多すぎるという候補は、同じ症状を説明できるので退けられず、どちらを選ぶかで確かめる方向が変わる。そこで推測で絞らず、仮説として残し、最初に確かめる前提に入れた。

> 出られなくなった家庭が自分で代わりを探す決まりのもとでは、交代のたびに個別の依頼が生まれ、見つからなければその手間が前夜の事務局へ移る。この一つの原因で、前夜の依頼、LINEの投稿の半分を占める交代のやり取り、当日の欠けを説明できる。説明できないのは、「自分の当番がいつか分からない」という問い合わせだけである。

## 最初に確かめる前提は、崩れたときの影響と根拠の弱さで選ぶ

四つの前提を点数で比べず、崩れたら何が起きるかと根拠が何かを文章で並べた。価値の前提は崩れると仮説がまるごと崩れ、根拠は又聞きだけなので、これを最初にした。確かめ方は、どの結果なら崩れたとするかを先に決めた。

> 5人のうち3人以上が、代わりを探した手間をいちばんつらかったこととして自分から挙げれば、前提は残す。多くが当番の回数や時間帯そのものを挙げたら、本質を当番の多さへ移し、この文書を書き直す。聞き取りの間は何も作らない。
