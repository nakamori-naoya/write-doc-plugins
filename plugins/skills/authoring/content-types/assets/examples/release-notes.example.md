# 2.3.0 — 2026-09-10

> これは [`release-notes.md`](../templates/release-notes.md) の記載例である。内部実装ではなく、利用者に見える変化を書く。

## 対応が必要な変更

なし。

## 追加

- 空き枠が埋まっているとき、順番待ちへ申し込めるようになった。
- 90分などの連続した利用枠を、一件の予約として取り消せるようになった。

## 変更

- 仮押さえ予約の残り時間を、分単位ではなく秒単位で表示するようにした。
- 空き状況の再読込時に、選択中の会議室を維持するようにした。

## 修正

- 日付変更直後に前日の空き状況が表示される時間を、最大30秒から最大5秒へ短縮した。
- 取消済み予約へ確認メールが送られる問題を修正した。

## 既知の問題

順番待ちの案内メールは、混雑時に最大2分遅れる場合がある。予約一覧には先に案内が表示されるため、急ぐ場合は画面を確認する。
