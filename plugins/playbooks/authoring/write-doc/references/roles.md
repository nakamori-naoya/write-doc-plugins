# 意味上の役 — 3つの関心をつなぐ契約

**文章規律は強調の役、図の設計は図の3役を決め、媒体はそれらをタグ・記号・図形へ写す。**

両者は互いを知らない。**参照するのはこの役の名前だけ**である。役の名前を契約にしておくと、媒体が増えても規律を書き換えずに済み、規律を差し替えても媒体側は動かない。

## 強調の4役

| 役 | 何を浮かせるか | HTML | Markdown |
|---|---|---|---|
| **要点** | その段落の主張 | `<mark>` | `**太字**` |
| **キーワード** | 中心概念の語（初出だけ） | `<mark class="kw">` | `` `バッククォート` `` |
| **一言でいうと** | 文書全体の主張（1文書に1つ） | `<p class="hitokoto">` | `> 引用` |
| **要約項目** | 冒頭要約の項目 | `<span class="badge imp">` / `<span class="badge pt">` | `**[最重要]**` / `**[ポイント]**` |

**役は4つで固定する。** 増やすと、どれも目立たなくなる。

## 図の3役

図を必須にするかは、上段が `requirements.figures` を boolean で解決し、図の工程が返した結果を `figures_required` と照合する。visual-guidanceへ必須判定を渡さない。

| 役 | 何を決めるか | HTML | Markdown |
|---|---|---|---|
| **図の主張** | 図だけを拾う人へ何を持ち帰らせるか | 図の直前の1文＋`<figcaption>` | 図の直前の1文＋画像直後のキャプション |
| **図の型** | 関係をどの視覚構造へ写すか | SVGの配置・座標・図形 | 外部SVGの配置・座標・図形 |
| **図の内容** | 位置・面積・個数・線へ何の意味を持たせるか | `<figure>` 内のインラインSVG | 外部`.svg`への相対リンク |

図の題材と型は図の設計が判断し、媒体はこの3役を描画表現へ写す。上段は役の名前と、図を必須にするかだけをつなぐ。

## 構造の役

資料の骨格に使う役。**CSS を持つものは、必ずここに書き方がある**（片方だけ在る状態を作らない）。

| 役 | 何に使うか | HTML |
|---|---|---|
| 冒頭要約 | 文書の頭に置く要点リスト | `<section class="summary">` |
| 末尾総括 | 構造で振り返る | `<section class="review">` ＋ `<ul class="structure">` |
| 出典の帰属 | 引用ブロックの出どころ | `<span class="attribution">` |
| 処理の流れ | 番号つきの手順 | `<div class="flow">` ＋ `<div class="step">` ＋ `<div class="num">` |
| 段階ブロック | 処理を実行順に読ませるときの、段階1つ分 | `<section class="stage" id="stage-N">` ＋ `<div class="stage-head">` ＋ `<span class="num">` |
| 段階の入出力 | 入力・確定する値・分岐・副作用・次の呼び出し | `<ul class="stage-io">` |
| 次の段階への導線 | 段階の末尾に置く送り | `<p class="next">` |
| 省略の印 | 載せなかった行があることを、その場所で示す | `<tr class="elision">` |
| 参照させるコード | 畳んでよいコード（**読ませるコードは畳まない**） | `<details class="code-listing appendix">` |
| 区分の印 | 新規／廃止などの分類 | `<span class="chip">` / `.chip.new` / `.chip.removed` |
| このファイルの責務 | コード解説で、対象の役割を先に置く | `<div class="file-purpose">` ＋ `<span class="label">` |
| 注意喚起 | マージ禁止など、読む前に知るべきこと | `<div class="warn">` |
| 横長の入れ物 | 表・図がはみ出すとき | `<div class="scroll-x">` または `<div class="tablewrap">`（同じ） |
| 資料の静的情報 | 末尾に載る期間・参加者・ラベル | `<section class="doc-meta">` ＋ `table.doc-meta-table` ＋ `<span class="label">` |

Markdown には対応する表現が無いものが多い。**無いものは無いと書き、代替を無理に作らない**（見出しと表と引用で足りる）。
