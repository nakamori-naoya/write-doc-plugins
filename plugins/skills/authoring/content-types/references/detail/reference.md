# 引くための型

## トラブルシューティング

**読み手**: 困っている人。急いでいる
**目的**: 症状から原因と復旧へ最短で導く
**成功条件**: 症状で引けること。原因の切り分けが分岐で書かれていること

読み手は教わりに来たのではなく、行動とその結果を引きに来ている。既知の問題が特定できたら書いて次の人を救う。既知の未解決を隠さない。
