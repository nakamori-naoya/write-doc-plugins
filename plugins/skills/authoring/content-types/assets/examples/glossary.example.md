# 用語集

> これは [`glossary.md`](../templates/glossary.md) の記載例である。RoomFlowで採用する語の意味と境界を示す。

## 利用枠

一つの会議室に対する利用開始から利用終了までの半開時間帯である。利用時間は30分単位の30分以上4時間以下で、90分の利用は一つの利用枠として扱う。

- **境界**: 会議室だけ、日時だけでは利用枠と呼ばない。10:00〜11:00と11:00〜12:00は重ならない
- **使う場面**: 予約同士が同じ会議室で重なるかを判断するとき

## 仮押さえ予約

顧客の利用意思を確認する間、利用枠を15分だけ他の顧客へ販売しない予約である。期限までに確定されなければ期限切れ予約になる。

- **境界**: 利用意思が確認された後は確定予約、期限到来で終了した後は期限切れ予約である
- **使う場面**: 予約担当者が短時間だけ販売機会を保留するとき

## 確定予約

顧客の利用意思が確認され、RoomFlowが会議室の提供を約束した予約である。

- **境界**: 仮押さえ予約は含めない。利用開始前の取消または利用終了まで提供責任が続く
- **使う場面**: 顧客へ会議室の提供を約束済みか判断するとき

## 仮押さえ期限が到来した

仮押さえ予約が確定されないまま、受付から15分後の時刻に達した業務イベントである。

- **境界**: 人が予約を取り消した事実ではない。期限管理担当が時刻到来を成立させる
- **使う場面**: 仮押さえ予約を期限切れ予約へ移し、利用枠を再販売可能にするとき
