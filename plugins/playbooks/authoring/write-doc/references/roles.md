# 意味上の役 — 3つの関心をつなぐ契約

**文章規律は強調の2役、図の設計は図の3役を決め、媒体はそれらを Markdown の記法へ写す。** 互いを知らず、参照するのは役の名前と印の記法だけである。**役の名前と印の記法がこの契約であり、ここにだけ定義する。** 役の名前を契約にしておくと、規律を差し替えても媒体側は動かず、媒体の記法を変えても規律は動かない。

## 強調の2役

契約名は `要点` / `キーワード`。draft 工程は本文（`body`）の中で、役を次の印で囲む。

| 役 | 本文中の印 |
|---|---|
| 要点 | `⟦要点: …⟧` |
| キーワード | `⟦キーワード: …⟧` |

印は入れ子にしない。冒頭の要点や文書全体の主張は見出しと段落が運び、印を付けない。役の付与は `writing-rules`、印から Markdown の記法（太字・バッククォート）への変換は `doc-render` が行う。この段取りは内容も記法も決めない。

## 図の3役

| 役 | 決定者 |
|---|---|
| **図の主張** | `visual-guidance` |
| **図の型** | `visual-guidance` |
| **図の内容** | `visual-guidance` |
| 型の固定図（content-types のカタログ「固定図を持つ型」） | テンプレート。`visual-guidance` は選び直さない |

Mermaid で描くか画像にするかも `visual-guidance` が決め、媒体はこの3役を Mermaid の記法か画像参照へ写す。

## 構造の役

骨格、出典、コード注釈の役も、上段が意味を確定し `doc-render` が Markdown の記法へ写す。この資料では Markdown の記法を定義しない。
