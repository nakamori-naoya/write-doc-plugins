# 強調（既定）

**強調の役は「要点」と「キーワード」の2つだけである。** 役の名前と本文への印の記法は write-doc の役の契約（`references/roles.md`）が持ち、どの記法へ写すかは媒体側が決める。 差し替える場合は `.harness-plugins/writing-rules.config.yml` の `rules.emphasis` に自分のファイルを指す。

| 役 | 何を浮かせるか |
|---|---|
| **要点** | その段落の主張 |
| **キーワード** | 中心概念の語（初出だけ） |

文書全体の主張と冒頭の要点は、役ではなく見出しと冒頭の段落が運ぶ（`structure`）。この2つ以外の目的で強調を使わない。装飾で使った瞬間、読み手は強調を信用しなくなる。

## 項目名は役ではない

`- **状態**: 承認`、`**なぜ**: …` のように、決まった位置で必ず同じ語が来る項目名は、役に数えない。項目名を消すと何の値か分からなくなるなら項目名、消しても文が成立するなら強調である。項目名はテンプレートが持つものだけを使い、自分で増やさない。

## どこへ当てるか

下敷きは `section` と同じ中野芳樹「客観的速読のための現代文読解法一覧」（[最新版 PDF](https://nakanogendaibun.com/wp-content/uploads/2026/05/9db385ece6cb4b91d836bafc7ba5a03a.pdf)）の R1〜R12。`section` の表が「こう書く」、この表が「だからここへ当てる」である。R9 は `section` の理由で欠番。

この表は主張と根拠を展開する文章での着眼点である。操作・参照が目的の文書では、必要な行動・値・条件を浮かせる。表に合う表現へ本文を作り替えない。

| | 場面 | 当てるのは | 当てないのは |
|---|---|---|---|
| **R1** | 具体例・比喩・引用 | 例の**直前か直後の抽象論** | **具体例そのもの**、引用符の中 |
| **R2** | 否定・比較（「AではなくB」） | **肯定側の B だけ** | 否定側の A |
| **R3** | 対比・対照 | **主題側の項だけ** | 従属側。主題が判別できない同等対比は**両方** |
| **R4** | 修辞疑問 | 問いと、対応する答え | 答えが特定できないときの答え側 |
| **R5** | 譲歩（「たしかに A」） | **逆接以降の本音 B** | 譲歩節そのもの |
| **R6** | 要約表現（「つまり」） | **後件** | 前件 |
| **R7** | 重視・強調（「重要」「本質」） | その節の要点 | 「重要である」という語だけの部分 |
| **R8** | 筆者の主観（「〜べきだ」） | その判断 | — |
| **R10** | 逆接（「しかし」） | 判断を変える限定や結論 | 接続詞そのもの |
| **R11** | 定義・命名 | 定義文を要点、**定義される語をキーワード** | — |
| **R12** | 要点並列（「第一に」） | 各要点 | 並列を示す語（「第一に」自体） |

**強調の失敗は、引き足りないことより、引いてはいけない場所へ引くことで起きる。** 上の場面のどれにも当たらない箇所は引かない。強調が無い段落は誤りではない。強調が無いことを理由に、前提・理由・具体例として必要な段落を削らない。比率は測らない。

キーワードにしてよいのは次の3つだけ。初出の1回、1文書に10語まで。キーワードは拾い読みで筋を追う目印なので、中心概念の数を超えて増やすと目印にならない。10語を超えるなら、中心概念が絞れていない。

1. R11 で定義・命名した当の語
2. 独自の意味を与えて繰り返し使う中心概念
3. 対比の軸になる一対の語（例: 線形／非線形）

## 当てる範囲

- 単位は文全体ではなく、述部を含む最小の節。主語が別の節にあるときだけ主語を含める。
- 修飾語は、外すと要点の意味が変わるときだけ含める。
- 同じ文で複数の規則が当たり、範囲が隣接・重複するなら、1つの連続した範囲に統合する。
- 同じ内容が反復されているなら、最初の1箇所だけ。
