# visual-guidance

**何を、どの図で伝えるかを決める。** 境界・レーン・凡例を固定配置する資料図では、参考画像を使った画像生成が適するかも判断する。文章の規律や媒体ごとの描画方法は持たない。

## 使う

```text
/choose-visual
```

依頼・本文・素材から読み手、目的、主要な主張を取り、図の主張・図の型・図の内容と挿入位置を返す。画像生成を選んだ場合は、同梱の参考画像と生成後の照合項目も指定する。

## 判断すること

- 図にする価値がある主要な主張はどれか
- 読み手が答えを得たい問いは何か
- [目的別の選択表](references/patterns.md)のどの型が合うか
- Mermaid で描くか、画像（固定レイアウトの画像生成）にするか
- 位置、形、線、色へ何の意味を持たせるか

## 判断しないこと

- 文章の構成・文体・強調
- Mermaid の記法と画像の置き場所（doc-render）
- 資料全体で図を必須にするか（write-doc の `references/figures.md`）
