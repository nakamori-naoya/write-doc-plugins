# 予約の作成から取消までを体験する

> これは [`tutorial.md`](../templates/tutorial.md) の記載例である。題材は架空の会議室予約サービスである。

完走すると、仮押さえ予約を確定し、不要になった確定予約を取り消す一連の流れを説明できる。所要15分。

完成時には丸の内店`M-301`の10:00〜11:30が`取消済み予約`として履歴に残る。

## 前提

[スタートガイド](getting-started.example.md)を完了し、RoomFlowが`http://localhost:8080`で動いていること。

## 手順

### 1. 仮押さえ予約を作る

`POST /v1/reservations`へ顧客`C-4102`、会議室`M-301`、2026-09-18 10:00〜11:30を送る。レスポンスの予約番号`R-20260901-0101`と仮押さえ期限09:15を控える。

**今どこにいるか**: 利用枠は15分間販売対象外になったが、顧客の利用意思はまだ確認されていない。

### 2. 予約を確定する

09:15より前に`POST /v1/reservations/R-20260901-0101/confirm`を実行する。レスポンスの`status`が`confirmed`になることを確認する。

**今どこにいるか**: RoomFlowが顧客へ会議室の提供を約束し、別の顧客は重なる利用枠を予約できない。

### 3. 予約を取り消す

`POST /v1/reservations/R-20260901-0101/cancel`へ理由`customer_requested`を送る。レスポンスの`status`が`cancelled`になることを確認する。

**今どこにいるか**: 利用枠は再び販売でき、顧客都合で予約が取り消された事実は履歴に残っている。

## 片付け

`docker compose down -v`を実行する。チュートリアル用のコンテナとデータだけが削除される。
