# 図の要件

## 必須かどうかを決めるのは、この段取りである

解決した設定の `requirements.figures` を読む。値は boolean だけを許す。
キーが無ければ同梱の既定値 `true` を使う。

| 値 | 意味 |
|---|---|
| `true` | **主要な主張を理解させる図を最低1つ要求する** |
| `false` | 図を必須にしない。**図を禁止する意味ではない** |

**資料かどうかを知っているのは、組み合わせる側だけである。** 図を選ぶ工程は
「この箇所は図にすると速い」を判断できるが、「図が無い成果物を許すか」は判断できない。
**下段へ必須判定を押し付けない。**

## 受け取った結果と照合する

図の工程からは、各図の**図の主張・図の型・図の内容**と挿入位置が返る。

`true` なのに、本文の主要な主張から選ばれた図が1つも無ければ、**保存工程へ進まない。**

**枚数を満たすための飾り図を作らせない。** 図にできる主張が無いなら、
無いことを報告して止める。**飾りで数を満たすと、次からその資料の図は読まれなくなる。**

## 媒体表現は保存先に従う

HTML ならインライン SVG、Markdown なら外部 SVG 参照など、**描き方は媒体側の手引きへ任せる。**
ここで決めるのは「図が要るか」「その図が主張を担っているか」だけである。
