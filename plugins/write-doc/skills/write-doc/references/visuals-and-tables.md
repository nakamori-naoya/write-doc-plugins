# 図・表・本文の役割

## 表現を役割で選ぶ

- 表は、候補の比較や属性の対応を俯瞰するために使う。
- 図は、構造、関係、境界、流れを直感的に示すために使う。
- 本文は、理由、因果、判断の背景を説明するために使う。

同じ情報を三つの表現へ重複させない。
図表を使わなくても関係が明瞭なら、本文だけで伝える。
図表の数を目標にしない。

## 表を短く保つ

セルには一つの値または短い要約を置く。
複数段落、長い論証、手順の全文をセルへ入れない。
比較軸が増えて横に追えない場合は、判断に必要な列だけ残す。
理由の詳細は、該当する行や表の直後の本文へ置く。

完全性が必要な定義一覧は表で保持してよい。
ただし、一つのセルへ複数の異なる判断を詰め込まない。

## 図を関係へ絞る

図には要素名、関係を表す線や矢印、短い遷移条件を置く。
説明段落、全属性、全制約、長い根拠を図へ入れない。
列定義、制約、詳細な条件は表または本文に置く。

図中の名称は本文と一致させる。
図に現れる主要要素は本文から参照できるようにする。
すべての本文要素を図へ載せることは求めない。

## コードを行動に結びつける

コードは、読者が実行または検証する範囲だけを示す。
前後の本文で、何を行い、何を観察すればよいかを示す。
長いコードを載せる必要がある場合は、焦点となる箇所を本文から参照する。

## 強調を限定する

太字は、読み飛ばすと判断を誤る語や短い要点に使う。
見出し直下の文全体を慣例で太字にしない。
強調が連続する場合は、見出しまたは文章構造で重要度を表す。
