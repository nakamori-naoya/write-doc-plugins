# 資料の地図の見本（抜粋）

この見本は、資料の地図で判断が分かれやすい箇所だけを抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 冒頭で、変更をどこから始めるかを言い切る

地図の読み手は、どの資料を最初に開くかを決めたいので、冒頭に変更の起点を一文で置いた。起点が型によって変わる題材なら、その分かれ目を書く。

> 図書館の貸出には六つの資料がある。決まりを変えるときは、必ず業務知識から直す。

## 判断ごとに、決める資料と写す資料を分ける

同じ値が二つの資料に現れるとき、どちらを直せば決まりが変わるかを取り違えやすいので、決める資料と写す資料を列で分けた。

| 判断 | 決める資料 | 写す資料 |
|---|---|---|
| 返却期限と貸出上限 | 業務知識 | ドメインモデル、コマンドデータモデル |
| 分離レベルと、やり直す回数 | 物理設計 | なし |

> コマンドデータモデルの返却期限の列は、貸したときに業務知識の決まりで決まった約束の写しである。そのため、列を直しても決まりは変わらない。

## 変更の種類ごとに、始める資料と順番を分ける

決まりを変える変更と、速さだけを変える変更では、触る資料が違う。変更の種類で見出しを分け、それぞれの順番を書いた。

> ### 貸出の検索を速くする
>
> 速さは業務の決まりを変えないので、物理設計だけを直す。
