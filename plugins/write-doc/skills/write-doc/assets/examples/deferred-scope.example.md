# 今は扱わないことの記録の見本（抜粋）

この見本は、今は扱わないことの記録で判断が分かれやすい箇所だけを抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 候補ごとに、今扱わない理由と、考え直す観測できる条件を書く

「いつか扱う」では誰も考え直す時を決められないので、考え直す条件を観測できる数で書いた。決める人がまだ決めていないことが理由なら、そう書く。

> 取り置きは、今の三つの行いだけでは利用者の不満が出ていないので、今は扱わない。取り置きの要望が窓口に月10件を超えたら、考え直す。

## 採らなかった案は、将来の候補と分ける

扱うかもしれない候補と、検討して退けた案は、読み手の次の行動が違うので節を分けた。退けた案には、退けた理由と、理由が崩れる条件を書く。

> 延滞した日数に応じて料金を取る案は、料金の計算と受け取りの業務が増えるわりに、返却が早まる根拠が無いため採らなかった。市の条例で延滞料を取るよう求められたら、考え直す。

## 仮に置いた値は、決める人と、決めるのに要るものを書く

仮の値は、決まっていないことが読み取れるように、根拠の仮定、決める人、決めるのに要る観測をそろえた。

> 延滞の通知を回収するときのリースは、10分と仮に置いた。送り先が30秒以内に応答するという仮定から置いた値で、決めるのは通知を運用する担当である。送り先の応答時間の実測を持ち寄って決める。
