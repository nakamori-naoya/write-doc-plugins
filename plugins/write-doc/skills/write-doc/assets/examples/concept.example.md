# 仮押さえ予約と確定予約は何が違うか

<!-- これは`concept`型の記載例である。構成の基準資料ではなく、粒度と具体性の見本として読む。RoomFlowは架空の貸会議室予約サービスで、時刻は説明用の例である。 -->

会議室を選んだ後に「仮押さえ」と表示されても、予約はまだ確定していない。仮押さえは顧客が利用意思を確かめるための15分間の保留であり、確定予約はRoomFlowが顧客へ会議室の提供を約束した状態である。

## 何を表すか

予約は一件ごとに、顧客と、その顧客が会議室を使う時間帯とを結びつける。この時間帯を利用枠と呼び、「明日の10:00〜11:30」のように表す。仮押さえでも確定予約でも、その枠を他の顧客へ重ねて販売しない。

両者の違いは、確定のための猶予が残っているかにある。仮押さえは受付から15分以内に利用意思を確認して確定する必要がある。期限時刻ちょうどになれば確定できず、仮押さえは期限切れになる。

## 具体的な場面でどう働くか

顧客が今日の10時に、明日の10:00〜11:30を仮押さえしたとする。場面は、この後に確定したかどうかで二つに分かれる。

10時10分に確定した場合は、今日の10時15分を過ぎても確定予約が残り、明日の利用枠は引き続きその顧客のために確保される。確定しなかった場合は、10時15分を過ぎると仮押さえが期限切れになり、明日の利用枠を他の顧客へ再販売できるようになる。

15分は会議室を利用できる長さではなく、予約を確定するまでの猶予である。先に確定した予約は、この猶予が終わっても消えない。

## どう考えると判断できるか

仮押さえを使えば、顧客は利用枠を保留したまま相談できる。一方で保留には期限があるので、意思が固まらない仮押さえが販売の機会をいつまでも塞ぐこともない。これはこの例の業務上の狙いであり、15分が最適だと実測した証拠ではない。

別の時刻に仮押さえしても、受付時刻から15分後を確定期限として判断する。11時に受け付けられたなら11時15分より前の確定が必要であり、11時15分ちょうどの確定は受け付けない。

確定予約も、取り消されれば終了する。「保留期限で消えない」ことは「取消不能」を意味しない。

## 理解の範囲と次に読むもの

この説明で、保留中なのか確定済みなのか、いつまでに確定が必要かを判断できる。誰が取り消せるか、予約資格を満たすかなどの判断は、[業務知識](domain-rule.example.md)を参照する。
