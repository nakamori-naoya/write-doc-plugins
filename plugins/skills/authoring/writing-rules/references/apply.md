# writing-rules の適用手順

## 規律の役割

| 規律 | 何を決めるか | 及ぶ範囲 |
|---|---|---|
| `structure` | 何をどの順で並べるか | 文書全体 |
| `section` | 各セクションの中をどう書き進めるか | セクション |
| `emphasis` | どの役をどこへ当てるか | 語・節 |
| `style` | 語り口・文の粒度・用語 | 文 |
| `citation` | 出典の3点セット。緩められない | 出典 |
| `annotated-code` | コードへ注釈を振るときの規律 | コード |

## 書き進め方

`structure` で骨格を決め、各セクションは `section` の手順で組み立てる。段落を書き終えるたびに `emphasis` で役を当てる。全体を書き上げてから強調箇所を探しに戻らない。

扱う役は `要点` / `キーワード` / `一言でいうと` / `要約項目` の4つだけ。役をどこへ当てるかは書き先に合わせて自分で選ぶ。役の名前を指定して呼ばれた場合は、その指定に従う。

## 出典だけは緩められない

`citation` は設定で差し替えられない。追加規律があっても、3点セットは外れない。出典に言及するなら、どこにあるか、そこに何と書いてあるか、だから何をしたかの3つを必ず揃える。

1つでも欠けるなら出典として書かない。存在しない出典・確認していない出典を書かない。
