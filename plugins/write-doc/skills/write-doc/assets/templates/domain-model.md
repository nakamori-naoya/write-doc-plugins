## クラス図

<!-- 書く: この文脈のすべての要素と関係を1枚に描く。集約が多く1枚で読めないときだけ、集約ごとに分けて、集約どうしの参照だけの図を1枚足す。
     記法は下の図のコメントのとおり。検査scriptはこの記法を構文解析する。 -->

```mermaid
classDiagram
    %% 種別は <<集約ルート>> <<エンティティ>> <<値オブジェクト>> <<ドメインイベント>> のどれか一つ
    %% コマンドは集約ルートとエンティティにだけ +コマンド名(引数) で書く。引数は同じ図のクラスのラベルにする。判定だけの操作とフィールドは書かない
    %% 業務の判断に使う時刻（貸出日など）は、コマンドが引数で受け取る値のクラスにする
    class Root["<集約ルートの語>"] {
        <<集約ルート>>
        +<コマンド名>(<判断に使う値の語>)
    }
    %% 複数の文脈で使う値は、種別に「・文脈共有」を添える
    class Shared["<ほかの文脈の識別子の語>"] {
        <<値オブジェクト・文脈共有>>
    }
    %% コマンドの成否を決める値は、それを成り立たせる業務の語を1行に1つ書く
    class Snapshot["<判断に使う値の語>"] {
        <<値オブジェクト>>
        <業務の語1>
        <業務の語2>
    }
    %% 取り得る値が限られる値は、その値を1行に1つ書く
    class Limited["<区分の語>"] {
        <<値オブジェクト>>
        <値1>
        <値2>
    }
    %% ドメインイベントは何も書かない
    class Happened["<ドメインイベントの語>"] {
        <<ドメインイベント>>
    }
    %% *-- は内側に持つ、--> は識別子で指す、..> はコマンドで受け取るか発する
    Root *-- Limited
    Root --> Shared : <何を指すか>
    Root ..> Snapshot : 受け取る
    Root ..> Happened : 発する
```
