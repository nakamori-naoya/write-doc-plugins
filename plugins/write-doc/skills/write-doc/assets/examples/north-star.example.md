# Product North Starの見本（抜粋）

この見本は、Product North Starの資料で判断が分かれやすい箇所だけを、電子チケットの題材から抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 望む状態は、手段ではなく受益者の状態で書く

この題材では「チケットを電子化する」を望む状態にせず、来場者が権利について何を心配しなくてよくなるかを書いた。電子化は手段で、紙のままでも満たせる状態があるからである。業務システムの題材なら、同じ判断で「誰のどんな仕事の状態が変わるか」を書くことになる。

> 来場者が紙の券面や特定の表示を保持しているかではなく、現在その人に有効な入場権があるかを関係者が共通して確かめられる。来場者は、会場へ着くまで「本当に入れるか」を心配し続けなくてよい。

退けた書き方は「入場の電子化率を9割にする」である。これは進み具合の指標で、戦略の側へ送る。

## 判断原則は、実際の二択を分けるものだけを置く

この題材で本当に迷うのは、不正を締め出す厳しさと、正当な来場者を救えることのどちらを取るかだった。そこで、その二択に答える原則だけを置き、「安全で便利に」のような何も捨てない標語は置かなかった。題材が変われば、迷う二択そのものが変わる。

> ### 不正を一律に締め出すか、正当な来場者を救済可能にするか
>
> 正当な権利を根拠をたどって回復できることを優先し、判断できない来場者を例外なく拒否すれば安全だとみなすことは選ばない。不正を減らしても、正当な人が権利を行使できなければ、約束した安心を損なうためである。

## 担わないことと、担う範囲の内側で選ばないことを分ける

販売条件や転売規制は主催者と立法が決めるので、担わないことに置いた。一方で、本人確認を一つの方法へ固定しないことは、担う範囲の内側で自ら選ばない方針なので、やらないことに置いた。二つを混ぜると、他者に委ねた責任と、自分が選ばなかった近道の区別が読めなくなる。

> イベントの販売条件、法令上の転売規制、会場の保安方針そのものを決めることは担わない。このプロダクトは、決まった条件を入場権の判定と説明へ矛盾なく反映するところを担う。

## 観測と仮説を分け、仮説には反証の方法を添える

聞き取りで得た回答は出典と観測時点を添えて観測に置き、そこから立てた見立ては反証の方法を添えて仮説に置いた。価値仮説に反する観測も、観測として残す。

> 同じ聞き取りのうち、年に一度しか来場しない想定来場者からは、権利の状態が事前に分かることより、当日に何も操作せず入れることを重視する回答があった。（出典：来場者聞き取り、観測時点：2026-08-01）
>
> 来場者の不安は、紙か電子かよりも、現在の入場権と拒否時の救済方法を事前に確認できないことから生じる。反証方法：媒体別に不安理由と救済の成否を聞き取り、権利状態を明示しても不安が変わらないか確かめる。
