# セクションの書き方（既定）

**各節は、読み手の1つの問いに答え、その答えを理解するのに足りる説明だけで支える。**

この規律が決めるのは、節の中の書き進め方である。節の順序は `path`、見出しと図表文の使い分けは `structure`、節の役は `argument`、目立たせ方は `emphasis` が決める。

## 読み手の問いへ答える

各節で読み手が解消したい疑問と、読み終えたときに分かる関係を決める。入口には答えか見通しを置き、理由・根拠・具体の場面で支える。初見では結論の語自体が理解できないなら、短い状況か定義を先に置く。見出しが答えを言い切っている節では、1文目で同じ主張を繰り返さない。

説明では、対象が何かだけでなく、何とどう関係し、条件によって何が変わるかを示す。原因から結果へ進む途中の判断を飛ばさず、読み手の既知のことだけで接続する。

## 段落は理解のまとまりで区切る

1段落は一つの問いへの答えと、それを理解するための説明をまとめる。別の問いや対象に移ったら段落を分ける。文の数では分けない。結論と理由、条件と結果はつながりが分かる距離に置く。短文をばらばらに並べて、関係を読み手に補わせない。

## 理解の飛躍に合う説明を選ぶ

具体例、比喩、比較、図、操作前後の変化は、読み手が関係をつかめない箇所に使う。用語集や短い手順のように、目的をすでに満たす説明へ抽象と具体の往復を追加しない。Given/When/Then は、型がその区画を固定見出しとして持つときだけ使う。

具体例は同じ対象を追い、登場する人物・値・状態が説明中のどの概念に対応するかを伝える。「仮押さえは15分で失効する」なら、10時に仮押さえした予約が10時15分にどうなるかを示し、その15分が利用時間なのか確定までの猶予なのかも区別できるようにする。

例が示す規則と適用範囲を、例の直前か直後の本文で結びつける。「つまり」で抽象論を再掲しない。例の中で新しい規則が現れたら本文へ戻して説明する。例から確かめられない範囲へ一般化しない。

誤解しやすい境界は、条件を一つ変えた対照例で示す。比喩は対応する点と対応しない点を区別する。

確認した事例は出典（`citation`）とともに使う。架空の例は「説明用の例」と明記し、実測・業務上の確定事項・検証済みの出力に見せない。

## 主張が立つ書き方（読解規則 R1〜R12 の裏返し）

下敷きは中野芳樹「客観的速読のための現代文読解法一覧」（[最新版 PDF](https://nakanogendaibun.com/wp-content/uploads/2026/05/9db385ece6cb4b91d836bafc7ba5a03a.pdf)、[2019年版 PDF](http://nakanogendaibun.com/wp-content/uploads/2019/04/dokkaiho2019-print.pdf)）。原典は**読む側**の規則で、たとえば R1 をこう定める。

> 具体例・比喩・引用（「たとえば」「〜のような」「〜など」「〜といった」で導かれる範囲、引用符内） | **要点としない**。その直前または直後にある抽象論を要点とする

本規律はこれを**書く側**へ裏返して使う。R 番号は原典と対応させてあるので、上の PDF と突き合わせて検証できる。同じ番号で「引く側」の規則は `emphasis` にある。

| | 場面 | こう書く |
|---|---|---|
| **R1** | 具体例・比喩・引用（「たとえば」「〜のような」「〜など」「〜といった」、引用符内） | 具体例がどの主張を支えるか、直前か直後の本文で分かるようにする |
| **R2** | 否定・比較（「AではなくB」「AだけでなくBも」「AよりむしろB」） | この形で書くなら **Bを言い切る**。Bが弱いなら形ごと変える |
| **R3** | 対比・対照（「Aは〜のに対しBは〜」「〜に比べて」） | 書く前に**どちらが主題か決める**。決まらない対比は書かない |
| **R4** | 修辞疑問（「〜とは何か」「なぜ〜か」） | 問いを立てたら**必ず答えを書く** |
| **R5** | 譲歩（「たしかに」「もちろん」「なるほど」「無論」） | 「たしかにA」を書いたら**必ず「しかしB」を続ける**。Bが無いなら譲歩ごと削る |
| **R6** | 要約表現（「つまり」「要するに」「結局」「このように」「言い換えれば」） | 「つまり」で始めたら、**その後件に主張の核を置く** |
| **R7** | 重視・強調（「重要」「本質」「前提」「原理」「〜こそ」「実は」「まさに」、最上級） | 「重要」と書くなら、**何がどう重要かまで書く**。語だけ置かない |
| **R8** | 筆者の主観（「〜と考える」「〜べきだ」） | 判断を書くときは**誰の判断か分かる形**にする |
| **R9** | 反語（「〜ではないだろうか」） | **使わない。** 読み手は答えを探しに来ている。番号は原典と対応させるため欠番にしてある |
| **R10** | 逆接（「しかし」「だが」「けれども」） | 前の説明のどこを修正・限定するのかを明らかにする |
| **R11** | 定義・命名（「〜とは…である」「…を〜と呼ぶ」「…を〜と名づける」） | 中心概念は**1回は定義する**。定義できないなら、その概念はまだ整理できていない |
| **R12** | 要点並列（「第一に／第二に」「まず／次に」「一方／他方」） | 独立した並列なら箇条書き、因果のつながりは文章で保つ。並べてよいのは文書の主張に役を持つ節・項目だけ（`argument`） |

原典が自ら課す制約も引き継ぐ。

> 判断に迷う箇所は「要点としない」を選ぶ。要点の少なさは誤りではない

この制約は `emphasis`「当てない側」の根拠である。
