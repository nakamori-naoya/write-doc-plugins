# 手順書の見本（抜粋）

この見本は、手順書で判断が分かれやすい箇所だけを抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 完了は、途中の成功と区別して書く

この題材では、仮押さえが作れた時点を完了と取り違えやすいので、冒頭で完了の状態を言い切った。途中で止まっても害の無い題材なら、この断りは要らない。

> 90分の会議を、一件の確定予約として登録する。仮押さえは確定までの保留なので、「仮押さえを作れた」だけでは完了しない。

## 結果が分からないときの一手を、手順の中に置く

操作の結果が不明なまま繰り返すと重複した予約ができるので、繰り返す前に確かめる手を手順の直後に置いた。やり直しても何も増えない操作なら、この一手は要らない。

> 確定操作の結果が分からないときは、新しい予約を作る前に控えた予約番号で状態を確認する。画面の待機表示が消えただけでは、確定したかどうかは分からない。

## 完了の確かめ方は、読み手が見るもので書く

完了は、読み手が画面で見て分かる表示で書いた。

> 控えた予約番号の詳細に、目的の会議室・日付・利用枠と「確定予約」が表示されれば完了である。
