# 業務知識の見本（抜粋）：計算が中心の業務

この見本は、計算が中心の業務で一つの事実の置き場に迷いやすい箇所だけを、勤怠の月次集計を題材に抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 区分を決定表に、量を式に書いた

「法定休日に働いた時間は休日労働、それ以外の日に8時間を超えた分は時間外労働」という説明には、その日がどの日か、どの時間が労働時間か、量をどう求めるかが混ざっている。文のままだと、所定休日に9時間働いた日を時間外労働に数えるかを、読む人が自分で組み立てる。そこで、日の区分を決定表に、量を式にした。区分の答えを、量の式が名前で使うので、式の中に場合分けは無い。所定休日の扱いを変えるときに直す所は、決定表の一行で済む。

決定表は、勤務カレンダーの指定のどの値にも行がちょうど一つある。量の式には単位と丸めを添え、境界ちょうどの答えを文で書いた。

日の区分を状況に置かなかったのは、きっかけで移り変わらず、勤務カレンダーという事実から導かれるからである。

```markdown
## 計算

### 日の区分

その日が始まる時点の勤務カレンダーを使う。その日が始まった後に勤務カレンダーが変わっても、その日の区分は変えない。

| 勤務カレンダーの指定 | 答え |
|---|---|
| 法定休日 | 法定休日 |
| 所定休日 | 所定休日 |
| 指定なし | 所定労働日 |

### 労働時間

式：労働時間 = 退勤の時刻 − 出勤の時刻 − 休憩の時間

単位：分

丸め：丸めない

確定した勤怠の記録の時刻を使う。

### 休日労働時間

| 日の区分 | 答え |
|---|---|
| 法定休日 | その日の労働時間 |
| 所定休日 | 0分 |
| 所定労働日 | 0分 |

### 時間外労働時間

式：時間外労働時間 = 最大( 時間外の対象になる労働時間 − 法定労働時間 , 0分 )

単位：分

丸め：丸めない

労働時間が法定労働時間に等しい日は0分である。

### 時間外の対象になる労働時間

| 日の区分 | 答え |
|---|---|
| 法定休日 | 0分 |
| 所定休日 | その日の労働時間 |
| 所定労働日 | その日の労働時間 |
```

抜粋なので、週の単位で数える時間外労働は省いている。

## 値があっても、外で決まるものは前提に置いた

「1日8時間」は値の範囲に見えるので、制約に書きたくなる。しかしこの値は法律が決め、この業務は当てにするだけである。置き場の問いは上から順に当てるので、制約より先に前提に当てはまる。どの日が法定休日かも、就業規則の業務が決めるので前提である。この業務の制約は、この業務自身が守る約束だけになる。

```markdown
## 前提

### 法定労働時間

1日の法定労働時間は8時間である。法律が決め、この業務は値を読むだけである。

### 勤務カレンダー

どの日が法定休日、所定休日であるかは、就業規則の業務が決める。この業務は、日ごとの指定を読むだけである。

### 確定した勤怠の記録

出勤、退勤、休憩の時刻は、打刻と修正の業務が決める。この業務は、その業務が確定した記録だけを読む。
```

## 状況は持たないと書き、表は計算を求めるきっかけの数行にした

月の集計には、きっかけで移り変わる在り方が無い。状況の節は消さず、持たないことを一文で書いた。表は、計算を求めるきっかけの二行だけである。行が少ないからといって、計算の場合分け（法定休日に働いた、8時間を超えた）を行に割らなかった。それは計算の中身で、きっかけへの答えは変わらないからである。未確定の記録はこの業務に届かないので、拒む行も作らなかった。

```markdown
## 状況

この業務は状況を持たない。月の集計は、確定した勤怠の記録から求め直すだけで、移り変わる在り方が無い。

## 行動・出来事と判断

同じ社員の同じ月へのきっかけは、確定した順に一つずつ表に当てはめる。

| いつ | 誰が | 何をすると | 何が起きる | どの決まりによるか |
|---|---|---|---|---|
| いつでも | アプリ | 月の勤怠の記録が確定した | 休日労働時間と時間外労働時間を求め、「月の勤怠を集計した（MonthlyAttendanceAggregated）」が起きる | 確定した勤怠の記録、休日労働時間、時間外労働時間 |
| いつでも | アプリ | 確定した勤怠の記録が訂正された | 休日労働時間と時間外労働時間を求め直し、「月の勤怠を集計し直した（MonthlyAttendanceReaggregated）」が起きる | 確定した勤怠の記録、休日労働時間、時間外労働時間 |
```

## BDD は、計算の境界と、区分で答えが変わる所に置いた

表の行が少ない業務では、BDD の大半が計算の例になる。量の境界ちょうど（法定労働時間に等しい日）と、区分が量の求め方を変える所（法定休日の長い労働を時間外労働に数えない）を選んだ。後者は、もっともらしい別の答え（休日労働にも時間外労働にも数える）を打ち消している。

````markdown
### [BDD-002] 労働時間が法定労働時間に等しい日は、時間外労働時間が0分である

```gherkin
Given: 2026年6月3日は所定労働日である
  And: 社員 E-0001 の確定した勤怠の記録は、出勤9時00分、退勤18時00分、休憩1時間である
When: 2026年6月の勤怠の記録が確定した
Then: 2026年6月3日の労働時間は8時間、時間外労働時間は0分である
```

### [BDD-005] 法定休日に10時間働いても、時間外労働時間には数えない

```gherkin
Given: 2026年6月7日は法定休日である
  And: 社員 E-0001 の確定した勤怠の記録は、出勤9時00分、退勤20時00分、休憩1時間である
When: 2026年6月の勤怠の記録が確定した
Then: 2026年6月7日の休日労働時間は10時間、時間外労働時間は0分である
```
````
