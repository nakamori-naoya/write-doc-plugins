# Product Strategyの見本（抜粋）

この見本は、Product Strategyの資料で判断が分かれやすい箇所だけを、電子チケットの題材から抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 診断は、状況を並べず、もっとも弱い環を一つ選ぶ

この題材では、紙の紛失、複製、譲渡後の混乱、入口の列という症状を並べて終えず、それらを一つの原因で説明できる課題を最重要課題に選んだ。題材が変われば弱い環も変わるが、「これを直さないと他を直しても全体が上がらない」と言えるものを一つ選ぶ判断は同じである。

> 最重要課題は、現在の入場権が誰にあり、正規にどう移り、いつ行使されたかを、購入から当日の救済まで一続きの根拠として扱えていないことである。このため、販売画面、転売監視、入口の読取速度を個別に改善しても、正当な来場者へ安心を届ける全体の力は上がらない。

## 基本方針は、魅力のある選択を捨てる理由と一緒に書く

入口の読取を速くする案は、着手から効果までが短く、捨てるのが惜しい選択だった。そこで同じ条件で比べ、それでも選ばない理由を書いた。捨てるのが惜しくない選択しか並ばないなら、方針はまだ何も選んでいない。

> 読取を速くする案のほうが着手から効果までが短く、当日の滞留という目に見える指標を先に動かせる。それでも入場権を一続きにする案へ集中するのは、権利の所在が説明できないことに由来する滞留は読取速度では消えず、非正規取引と正規譲渡後の混乱には一切効かないためである。速さの改善は入場権が一続きになった後なら同じ設備のまま重ねられるが、逆順では作り直しになる。

やらないことは、永久に選ばないという意味ではなく、この期間に資源を配らないという選択として書いた。

## 行動は、前の行動が次を可能にする鎖にする

三つの行動を並べるだけでは寄せ集めになる。この題材では、各行動の段落に、前の行動の何を受けて成り立つかを書いた。

> 来場できなくなった人が入場権を正式に手放し、新しい来場者が自分の権利として受け取れる経路を、販売後の標準的な選択肢にする。行動1で入場権の所在を一つにしたからこそ、移転の成立と同時に古い保有者の権利を終わらせられる。

## 最初の到達状態は、次の障害が見える地点に置く

到達状態を「全主催者へ展開する」のような遠い成果にせず、限定した範囲で経路が一通り成り立ち、次に何が全体を止めるかを観測できる地点に置いた。

> 限定した主催者の公演で、正規購入、来場不能時の譲渡、新しい保有者の入場、問題時の救済までを一つの入場権から説明できる。この状態へ到達すれば、次に全体を止めるものが本人との結び付き、通信、正規経路の使いやすさのどれかを観測できる。
