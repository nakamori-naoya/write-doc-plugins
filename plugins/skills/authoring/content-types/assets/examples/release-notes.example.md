# 2.3.0 — 2026-09-10

> これは`release-notes`型の記載例である。**構成の正本ではなく、粒度と具体性の見本として読む。**RoomFlowの変更・公開日・時間の値は架空であり、実在するリリースや測定結果を示さない。

予約者向けの更新である。順番待ちへの申込みと連続した利用枠の取消ができるようになる。既存予約の取り直しや設定変更は不要である。

## 対応が必要な変更

なし。保存済みの予約内容と確定期限は変わらず、そのまま利用できる。

## 追加

- 対応する会議室では、空き状況画面の「順番待ち」から、埋まっている利用枠を待てるようになった。申込み後は予約一覧に「順番待ち中」と表示される。この表示だけでは部屋を確保していない。先の予約が取り消されると、受付順が最も早い順番待ちが自動で仮押さえ予約へ繰り上がり、表示が「仮押さえ中」と確定期限に変わる。
- 90分などの連続した利用枠を、予約詳細の「予約を取り消す」から一件まとめて取り消せるようになった。10:00から11:30までの予約なら、90分全体が取消になる。一部の30分だけを取り消す操作は含まない。

## 変更

- 仮押さえ予約の残り時間を、分単位ではなく「02:30」のように秒単位で表示するようにした。確定までの15分という期限は変わらない。
- 空き状況の再読込時に、選択中の会議室を維持するようにした。

## 修正

- 日付変更後に空き状況を再読込しても、前日の内容が残る問題を修正した。
- 取消済み予約へ確認メールが送られる問題を修正した。

## 既知の問題

順番待ちが繰り上がったことを知らせるメールは、混雑時に2分程度遅れる場合がある。予約一覧には先に「仮押さえ中」と確定期限が表示される。メールを待たずにその画面から確定へ進めるが、**確定期限は繰上げの時点から15分であり、メールの到着で延びない。** 期限を過ぎると仮押さえは期限切れになり、次の順番待ちが繰り上がる。
