# 場面

<!-- 書く: 開始地点から最終地点までを順番に分けた場面。各場面の結果から次の場面の前提へ渡る状態。
     場面と分岐は、主たるユーザーが観測できる振る舞いだけで書く。判定は「この違いが起きたとき、主たるユーザーは何を見て気づくか」。気づかないなら書かず、書かないものへの断り書きも書かない。
