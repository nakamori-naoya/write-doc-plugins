# 追う型

## 期間ダイジェスト

**読み手**: その期間の動きを追う必要がある人（不在だった人、次の会に出る人）
**目的**: 期間内に起きたことを状態別に1枚へ集める
**成功条件**: これ1枚を読めば、次の会に出られる

教える文書ではなく、追う文書である。読み手はすでに文脈を持っていて、散らばった事実を状態順に並べ直したものを求めている。

区画は4つに固定する。**決定／未決／アクション／動き**（カタログ「固定見出しを持つ型」）。

すべての項目から元の記録へ戻れること。素材が URL を持っていれば各項目に出典リンクを付け、無いなら推測で書かず「出典なし」と明記する。戻れない要約は、疑われた時点で使われなくなる。

素材が複数のソースにまたがるときも1枚にまとめる。同じ論点が「会議で相談 → チャットで決着」と移動するので、ソースで分けると追えなくなる。区別は各項目のソース表示で足りる。
