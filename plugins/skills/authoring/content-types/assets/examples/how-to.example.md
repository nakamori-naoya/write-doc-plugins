# 会議室を90分の一つの利用枠として予約する

> これは [`how-to.md`](../templates/how-to.md) の記載例である。目的が明確な利用者向けに、背景を広げず解決手順だけを書く。

RoomFlowでは、一件の予約が一つの連続した利用枠を持つ。90分の利用は30分の予約3件へ分割せず、開始10:00・終了11:30の一件として仮押さえし、期限内に確定する。

## 前提条件

- RoomFlow 2.3以降を利用していること
- 会議室M-301の2026-09-18 10:00〜11:30に有効な予約がないこと
- 顧客C-4102が予約可能顧客であること
- 顧客C-4102の仮押さえ予約が2件以下であること

## 手順

1. 丸の内店の空き状況で、会議室M-301と2026-09-18 10:00〜11:30を選ぶ。
2. 顧客C-4102と用途「採用面接」を指定し、「仮押さえ」を選ぶ。
3. 予約番号`R-20260901-0101`、利用枠10:00〜11:30、仮押さえ期限09:15を確認する。
4. 顧客の利用意思を確認し、09:15より前に「予約を確定」を選ぶ。
5. 予約状態が「確定予約」、利用枠が10:00〜11:30の一件であることを確認する。

## 確認

- 予約一覧に`R-20260901-0101`が一件だけ表示される。
- 利用開始10:00、利用終了11:30、予約状態「確定予約」と表示される。

## うまくいかないとき

- 10:00〜11:30の一部でも別の有効な利用枠と重なる場合は、[トラブルシューティング](troubleshooting.example.md)の「希望時間の一部が空いていない」を確認する。
- 09:15を過ぎた場合は元の予約を確定せず、最新の空き状況から新しい仮押さえ予約を作る。
