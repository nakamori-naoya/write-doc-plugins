# 本文、表、図の受け持ち

本文は、理由、因果、判断の背景を語る主役である。表は、同じ属性を持つものを行をまたいで比べるときに使い、図は、構造、関係、境目、流れを一目で見せるときに使う。受け持ちを混ぜると、表は読めない長文のセルになり、図は文字で埋まる。

## 表だけで資料を組まない

表を続けて並べるだけでは、読み手は何に注目すればよいかが分からない。表を置いたら、前後の本文で、その表の何を見れば判断できるのかを書く。同じ情報を本文と表と図の三つで繰り返さないが、表で一覧を見せ、本文で納得の理由を語るのは重なりではない。図表が無くても関係が明らかなら、本文だけで書く。図表の数を目標にしない。

## 表と箇条書きを使ってよい場面は、書くときの規範に従う

表と箇条書きを使ってよい場面は、[書くときの規範](writing-norms.md)の「箇条書きと表は、使ってよい場面を決めておく」が一か所で決める。項目ごとに、なぜそうするのか、どう動くのか、どんな条件や例外があるのかを語る必要があるなら、表に押し込まず、項目ごとに小見出しを立てて本文で書く。

## 図には、要素と関係だけを描く

図には、要素の名前、関係を表す線や矢印、短い遷移の条件を置く。説明の段落、すべての属性、すべての制約、長い根拠は図に入れず、表か本文に書く。図の中の名前は本文と同じにし、図の主な要素は本文から指せるようにする。本文の要素をすべて図に載せる必要はない。

## code は、読み手が動かす範囲だけ載せる

code は、読み手が実行するか確かめる範囲だけを載せる。前後の本文で、何をして、何を見ればよいかを書く。長い code を載せるときは、見てほしい箇所を本文から指す。

## 太字は、読み飛ばすと判断を誤る語だけに使う

太字は、読み飛ばすと判断を誤る語や短い要点に使う。見出しのすぐ下の文を、慣れで丸ごと太字にしない。強調したいところが続くなら、太字を重ねず、見出しや文の組み立てで重みを示す。
