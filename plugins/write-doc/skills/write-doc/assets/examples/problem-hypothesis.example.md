# 課題と価値仮説 — 少年サッカークラブの当番

事務局を疲れさせているのは当番表の見にくさではなく、当番に出られなくなった家庭が自分で代わりを探す決まりである。ただし、保護者のつらさが本当に代わり探しにあるのかは、まだ保護者本人から聞けていない。そこで、何かを作る前に、最近当番を交代した保護者5人に、その週に何が起きたかを聞いて確かめる。

依頼は、事務局の担当者から「当番表のアプリを作りたい」という形で届いた。この文書は、事務局の担当者とコーチが、アプリを作る前に何を確かめるかを決めるために読む。依頼者の言う「当番表」の困りごとは症状の一部にすぎず、本質は交代の手間が一部の人に集まることにある、と見立てた。何を作るか、クラブが長く何を目指すかは、この文書では決めない。

## 起きていること

クラブには小学生40人が所属し、家庭ごとに月2回、配車、給水、グラウンド準備のどれかの当番が割り当てられる。当番に出られない家庭は、自分で代わりの家庭を探して事務局へ伝える決まりになっている。

### 事務局の担当者は、試合の前夜に代わりを探していた

9月6日の練習試合の前日、配車当番の2家庭から、夜9時を過ぎて出られないと連絡があった。担当者はほかの保護者へ個別に電話とLINEで頼み、夜11時過ぎに1家庭の代わりが決まった。もう1台は決まらず、当日はコーチが自分の車で2往復した。（出典：事務局の担当者の発言、観測時点：2026-09-12）

8月のLINEグループの投稿312件のうち、およそ半分が当番の交代の依頼とその返事だった。一方で、交代の依頼に応じた家庭は延べ20件あった。（出典：事務局の担当者がLINEの履歴を数えた結果、観測時点：2026-09-12）

### コーチは、当番の欠けを当日に埋めていた

同じ9月6日、配車が1台足りず、試合の開始が20分遅れた。コーチは、月に1回はこうした欠けを当日に自分で埋めていると話した。（出典：コーチの発言、観測時点：2026-09-12）

### 保護者の困りごとは、まだ又聞きである

事務局の担当者は、共働きの保護者から「代わりを探すのがいちばんしんどい」と聞いたことがあると話した。保護者本人からは聞けていないので、これは仮説として扱う。（出典：事務局の担当者の発言、観測時点：2026-09-12）

## 本質は、交代の手間が出られない家庭と事務局に集まること

出られなくなった家庭が自分で代わりを探す決まりのもとでは、交代のたびに個別の依頼が生まれ、見つからなければその手間が前夜の事務局へ移る。この一つの原因で、前夜の個別の依頼、LINEグループの投稿の半分を占める交代のやり取り、当日の欠けとコーチの穴埋め、保護者の「代わり探しがしんどい」という声を説明できる。説明できないのは、「自分の当番がいつか分からない」という問い合わせだけである。

### 当番表の見にくさと、当番の多さ

当番表は月初にPDFでLINEへ流れるだけで、見にくいのは確かである。ただ、見やすくなっても出られなくなる家庭は減らないので、前夜の依頼と当日の欠けは説明できない。

当番の回数そのものが家庭の事情に比べて多い、という候補は退けられない。これなら欠けも交代のやり取りも説明できる。どちらが本質かで確かめる方向が変わるが、見分けるには保護者本人の出来事が要る。そこで、推測で絞らずに仮説として残し、最初に確かめる前提に入れた。

## 当番表のアプリは、問い合わせは減らすが前夜の依頼は残す

依頼者がアプリを思いついたのは、毎週の「私の当番はいつ？」への返事と、交代のたびに表を差し替える手間を無くしたかったからである。アプリで表が見やすくなれば問い合わせは減る。しかし、代わりを探すのが出られない家庭である限り、前夜の個別の依頼と当日の欠けは残る。表は、下の方向で交代を受け付ける場所の一部としてなら役に立つ。

## 価値仮説

当番に出られなくなった保護者が、試合や練習の前の週に、自分で代わりを探さずクラブへ交代を申し出るだけで済めば、前夜の個別の依頼と当日の当番の欠けがなくなり、それは試合前日の18時以降に事務局が送る個別の依頼の件数で分かる。

## 確かめる方向

### 交代の申し出を一か所で受け、控えから埋める

その週に手が空く保護者があらかじめ手を挙げる控えの枠を作り、交代の申し出はそこから埋める。代わり探しの手間が出られない家庭から消え、前夜の依頼と当日の欠けに効くと見込む。最初は事務局が手作業で回せる。

### 当番を割り当てから募集へ変える

家庭ごとに割り当てるのをやめ、出られる人が週ごとに手を挙げる形にする。交代そのものが無くなるが、クラブの決まりを変えることになる。当番の多さが本質だった場合にも効く。

## 前提と危うさ

価値の前提は、保護者のつらさが代わり探しにあることである。当番の多さにあるなら、交代を楽にしても不満も欠けも残り、価値仮説がまるごと崩れる。根拠は事務局の担当者の又聞きだけで、四つの中でいちばん弱い。

実現性の前提は、控えの枠に毎週手を挙げる保護者が集まることである。集まらなければ最初の方向は成り立たない。影響は大きいが、8月に交代の依頼へ延べ20件応じた家庭があり、手を貸す人がいる根拠はある。

保護者がLINEグループの外にある申し出の場所を使うか、という使いやすさの前提は、崩れても影響が小さい。使われなければ、申し出をLINEの個別の窓口で受ければ回る。

事業性では、当番を家庭の義務とする今の決まりを、保護者会が募集へ変えられるかが危うい。根拠はまだ無いが、崩れて困るのは二つ目の方向だけである。

## 最初に確かめること

保護者のつらさが代わり探しにあるのか、当番の多さにあるのかを確かめる。次の2週間で、最近当番を交代した保護者5人に、最後に当番に出られなかった週に何が起き、どうしのいだかを聞く。何が欲しいか、アプリを使うかは聞かない。

5人のうち3人以上が、代わりを探した手間をいちばんつらかったこととして自分から挙げれば、前提は残す。多くが当番の回数や時間帯そのものを挙げたら、本質を当番の多さへ移し、この文書を書き直す。聞き取りの間は何も作らない。

## 未決

### 当番の決まりを変える判断は誰がするか

当番を募集へ変えるのを、事務局が決めてよいのか、保護者会の合意が要るのかは分かっていない。答えによって二つ目の方向を確かめる相手が変わる。確認先・方法：事務局の担当者と保護者会の会長に、これまで決まりを変えたときの手順を聞く。
