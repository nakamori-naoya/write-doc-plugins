# 文章の基本原則

## 読後ゴールを固定する

主な読み手を一人または同じ目的を持つ一群に絞る。
読み手が文書を読んだ後にできる判断または行動を定める。
背景知識の説明は、その到達点に必要な範囲に限るが、読み手が納得して判断するために必要な文脈（なぜその課題が生じたか、なぜその選択肢なのか）は削らない。

## 答えを先に示し、文脈で支える

冒頭で読者の中心的な問いに答える。
見出しは、その節で得られる答えまたは扱う対象を示す。
結論を先に提示した上で、読者が「なぜそう言えるのか」を直感的に理解できるよう、背景・理由・対比をストーリーとして滑らかに繋ぐ。

## 論理のつながる自然な文にする

一文で伝える中心的な論理を一つにする。
因果（〜であるため〜となる）、対比（〜の一方で〜である）、転換（〜ではなく〜である）のように、前後の関係が密接に結びついた一つの思考は、無理に短い単文へ解体しない。
文を細切れにして読者に文と文の接続を推測させる負担を避ける。
主語と述語の対応を崩さない範囲で、因果関係が一目でわかる自然な長さの文にする。

日本語説明文の 40〜60 文字は、読みにくい複文を見直す目安にすぎない。
文字数は合否条件ではない。
自然な因果や対比が流れるように読める文を、長さだけを理由に分割しない。

## 一段落に一つのトピックを置く

段落の冒頭に要点を置く。
続く文は、その要点を読者が理解するために必要な理由、背景、条件、具体例を順序立てて支える。
規則や属性を単に並べるのではなく、なぜその問題が起き、どのような因果や仕組み（メカニズム）で解決されるのかを本文で丁寧に語る。
別の問いや新しい論点へ移るときは段落を分ける。

形式的な型枠を埋めるためだけに理由や具体例を水増ししないが、読者の腹落ちに必要な説明を省略しない。

## 概念の一貫性と、直感的な言い換えを両立する

一つの概念・実体には一つの正式名称を一貫して使う。専門語や略語は初出で定義する。
ただし、読者の直感的な理解を促すための平易な言い換えや具体例（「要するに〜ということである」「身近な例で言えば〜に相当する」）を恐れず添える。
用語の厳密な固定と、メンタルモデル構築のための噛み砕きは両立する。

## 必要な構成だけを残す

読者の問いへ答える順序で節を並べる。
テンプレートは必要な論点を発見する案内であり、全見出しを埋める義務ではない。
素材に根拠がない内容は、空欄を埋めるために推測しない。ただし、素材にある事実を読者が理解しやすいよう、一般的な知識や論理で解説・肉付けすることは捏造ではない。

## 理解の足場を保ちながら推敲する

削っても読者の理解、判断、行動が変わらない無駄な記述を削る。
エージェントの自己防衛のためだけの言い訳、官僚的な注釈、内容のない紋切型の前置きを除く。
一方で、読者の直感的な納得感を支える背景説明（Why）、動作のメカニズム、重要な条件、反例、平易な解説・アナロジー・具体例は、理解の足場（Scaffolding）として削らない。

推敲に削減率を置かない。
文字数を減らすこと自体を目的にせず、読者が迷わず理解し、判断へ到達できる文章になっているかで判断する。
