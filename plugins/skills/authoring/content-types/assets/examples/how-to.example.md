# 会議室を90分の一つの利用枠として予約する

> [`how-to.md`](../templates/how-to.md)の記載例。RoomFlowは架空のサービスで、画面名・予約番号・時刻は説明用である。実際の操作結果を記録したものではない。

90分の会議を、開始10:00・終了11:30の一件の確定予約として登録する。仮押さえは確定までの保留なので、「仮押さえを作れた」だけでは完了しない。

## 始める前に

予約可能な顧客について、操作権限のある拠点の空き状況を確認できることが前提となる。例では顧客C-4102、丸の内店M-301、2026-09-18の10:00〜11:30を使う。実際には自分が予約する顧客・部屋・日付へ置き換える。

仮押さえ数の上限や予約資格を満たすことも必要である。満たさない場合はこの手順を繰り返さず、[業務知識](domain-rule.example.md)の該当条件を確認する。

## 手順

1. 空き状況で目的の部屋と日付を開き、開始10:00・終了11:30を選ぶ。90分を30分ずつの別予約へ分けない。
2. 顧客と用途を指定して「仮押さえ」を選ぶ。成功したら、実際に表示された予約番号と確定期限を控える。
3. 仮押さえ詳細で、部屋・日付・利用枠が意図どおりかを確認する。例として9月1日09:00に受け付けられたR-101なら、確定期限は同日09:15となる。この期限は9月18日の会議開始時刻とは別である。
4. 顧客の利用意思を確認し、表示された期限より前に、その予約の「予約を確定」を選ぶ。期限ちょうどでは確定できないため、その場合は下の「期限切れ」の行へ進む。

確定操作の結果が分からないときは、新しい予約を作る前に控えた予約番号で状態を確認する。画面の待機終了だけでは、確定したかどうかは判断できない。

## 完了を確認する

控えた予約番号の詳細に、目的の部屋・日付・10:00〜11:30の利用枠と「確定予約」が表示されれば完了である。予約一覧でも、今回の操作で同じ利用目的の予約を重複して作っていないことを確認する。

## 想定と違う場合

| 見えている結果 | 確かめること | 次にすること |
|---|---|---|
| 希望枠が取れない | 選んだ日付と90分全体の空き | 空き状況を読み直し、別の枠を選ぶ |
| 仮押さえが期限切れ | 控えた予約の状態と期限 | その予約は確定せず、現在の空き状況から新しく仮押さえする |
| 確定操作の結果が不明 | 控えた予約番号の現在状態 | 確定済みなら完了確認へ。仮押さえのままで期限前なら同じ予約を確定する |
| 予約の状態自体を確認できない | 予約番号と操作時刻を控えているか | 新規予約を増やさず、状態確認を依頼する |
