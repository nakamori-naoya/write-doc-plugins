# 出典の扱い（差し替え不可）

**出典に言及するなら、どこにあるか・そこに何と書いてあるか・だから自分は何をしたか、の3点を揃える。1つでも欠けるなら、出典として書かない。** `rules.citation` に別ファイルを指しても resolver が拒否する。文書の信頼は出典の正確さだけで担保される。

## 3点セット

1. **どこにあるか** — URL（Web）または書誌情報（書名・著者・訳者・出版社・刊行年・ISBN）
2. **そこに何と書いてあるか** — 原文そのままの引用
3. **だから自分は何をしたか** — 引用を受けた自分の判断

**引用が日本語以外なら、逐語引用の直後に日本語訳を添える。** 訳は「訳」と明示し、原文を省かない。訳は逐語引用ではないので、引用符の中に入れない。

3つが「ここにこう書いてあるから、こうした」という形になる。連続する引用は、1つの判断でまとめて受ける。読み手はこれを見て自分で原典に当たって検証できる。検証できない出典は、出典ではなく飾りである。

## やってはいけないこと

| | なぜ駄目か |
|---|---|
| **存在しない出典を書く** | 書名・URL・章番号・ページ番号を推測で書かない |
| **確かめていない出典を書く** | 記憶にある書名を確認せずに書かない。確認できないなら書かない |
| **引用なしで出典名だけ書く** | 「〜を参考にした」で終わると、読み手は何が借り物で何が自分の考えか分けられない |
| **引用のふりをした要約を書く** | 引用符の中身を1文字でも変えたら引用ではない。要約なら「要約」と書く |
| **外国語の引用に訳を付けない** | 読み手は日本語で読む。訳が無い引用は根拠を追えない |
| **二次情報を一次情報として書く** | ブログ記事で読んだ内容を、原典を読んだかのように書かない。読んだのはブログ記事である |
| **リンク切れを放置する** | 書く時点で開けることを確かめる。開けないなら、開ける版を探すか出典を落とす |
| **確認範囲を超えて帰属させる** | 引用画像や抜粋だけを読んだなら、その範囲を明記する。書籍全体を確認した扱いにしない |

## 引用を出せないとき

「出典」と書かない。代わりに、何をどこから借りたのかを名指しする。

```markdown
<!-- 駄目 -->
出典は『◯◯』。

<!-- こう書く -->
コンテンツタイプの分類と名称は『◯◯』（書誌情報）から借りている。**逐語の引用は含まない。**
```

手元に原典が無いなら、原典を読んだ形で書かない。「screenshots で見た」「人から聞いた」なら、そう書く。
