# ユーザー目的達成BDDの型

## ユーザー目的達成BDD

**読み手**: ユーザーの目的達成を共通理解にしたい業務担当者、プロダクト担当者、開発者、テスター

**目的**: 何であるか／何ではないかを判定済みのUser Journeyについて、目的を持つユーザーが開始地点から複数の意味ある場面を経て、目的が満たされた最終地点へ到達するまでを一続きに読めるようにする

何がJourneyで何がJourneyでないかの判定、両端、場面接続、BDDの妥当性は呼び出し元のUser Journey専門pluginまたは依頼が与える。content-typesは内容を発見・補完せず、同梱の骨格と記載例だけを渡す。
