# Markdown で出す

## 強調

| | 書き方 |
|---|---|
| 要点 | `**太字**` |
| キーワード（初出のみ） | `` `バッククォート` `` |

**どこに引くかの規則は `emphasis` ガイド**（設定で差し替え可）。HTML の2色マーカーに相当するものが Markdown には無いため、この2つで代替する。**太字を装飾に使わない**（強調規則で特定した箇所だけに使う）。

## 骨格

```markdown
# タイトル

> 型: ハウツーガイド ／ 読み手: …

（一言でいうと。1〜2文）

## 全体像
（図または表）

## …
```

## 図

**インライン SVG を書かない。** 多くの Markdown ビューアが描画しない。外部の `.svg` を作って相対パスで参照する。

```markdown
![分割の断面は外部依存の重さ](assets/fig-01-overview.svg)
```

図で伝えたいことが**表で足りるなら表にする**。Markdown では表のほうが確実に読める。

## 段落

**段落の切れ目は空行で出す。** Markdownの単なる改行は段落を割らない。文章側が段落を割ったなら、必ず空行が1つ入っている状態にする。

**段落を空行で割らないと、文章側の規律が出力で消える。** 1段落1主張として書いたものが、レンダリング後は1つの長い塊になる。

## 表

- 桁揃えのために空白を詰めない（読み手はレンダリング後を見る）。
- セルを長くしない。長い説明は表の外へ。

## リンク

- パスは**その文書からの相対パス**にする。
- スペースや記号を含むパスは `<...>` で囲む。

## 出す前に

- [ ] 段落ごとに空行が入っている（1段落＝1ブロック）
- [ ] 太字が強調規則で特定した箇所だけになっている
- [ ] キーワードが初出だけ
- [ ] 図が外部ファイル参照になっている
- [ ] リンクが切れていない
- [ ] 秘匿が入っていない
