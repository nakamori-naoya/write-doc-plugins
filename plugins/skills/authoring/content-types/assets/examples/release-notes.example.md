# 2.3.0 — 2026-09-10

> これは [`release-notes.md`](../templates/release-notes.md) の記載例である。RoomFlowの変更・公開日・時間の値は架空であり、実在するリリースや測定結果を示さない。

予約担当者向けの更新である。順番待ちへの申込みと連続した利用枠の取消ができるようになる。既存予約の取り直しや設定変更は不要である。

## 対応が必要な変更

なし。保存済みの予約内容と確定期限は変わらず、そのまま利用できる。

## 追加

- 対応する会議室では、空き状況画面の「順番待ち」から、埋まっている利用枠を待てるようになった。申込み後は予約一覧に「順番待ち中」と表示される。この表示だけでは部屋を確保していない。
- 90分などの連続した利用枠を、予約詳細の「予約を取り消す」から一件まとめて取り消せるようになった。10:00〜11:30の予約なら、90分全体が取消になる。一部の30分だけを取り消す操作は含まない。

## 変更

- 仮押さえ予約の残り時間を、分単位ではなく「02:30」のように秒単位で表示するようにした。確定までの15分という期限は変わらない。
- 空き状況の再読込時に、選択中の会議室を維持するようにした。

## 修正

- 日付変更後に空き状況を再読込しても、前日の内容が残る問題を修正した。
- 取消済み予約へ確認メールが送られる問題を修正した。

## 既知の問題

順番待ちの案内メールは、混雑時に2分程度遅れる場合がある。予約一覧には先に「ご案内中」と期限が表示される。メールを待たずにその画面から進めるが、表示された期限はメールの到着で延びない。期限を過ぎた案内からは申し込めない。
