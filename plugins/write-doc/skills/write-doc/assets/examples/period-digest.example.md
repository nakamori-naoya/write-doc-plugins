# 期間ダイジェストの見本（抜粋）

この見本は、期間ダイジェストで判断が分かれやすい箇所だけを、会議室予約プロジェクトの一週間の題材から抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 時間順を、期間の終わりの状態へ並べ替える

素材は会議ごとの時間順だったが、読み手が次の定例で要るのは、いま何が決まり何が開いているかである。この題材では、8月27日の重複予約の事象そのものは「この期間の動き」に短く置き、それを受けて28日に決まったことだけを「決まったこと」に載せた。

| 決定 | いつ | 誰が | 出典 |
|---|---|---|---|
| 枠占有の書込みへDBの排他制約を追加する | 2026-08-28 | RoomFlow技術責任者、DB担当 | 技術設計レビュー（出典なし） |

## 未決は、何が決まれば閉じるかと一緒に書く

話題に上がっただけのものは未決にせず、問いの形にできて、閉じる条件が言えるものだけを載せた。

> 取消履歴を何年間保持するか。法務と監査が期間へ合意すれば閉じる。2026-08-25 から開いている（データ設計レビュー、出典なし）。

## 出典に戻れないものは、戻れないと書く

URLを持たない素材は、推測したリンクを置かず「出典なし」と書き、素材の節には拾わなかった件数も書いた。

> 拾わなかった素材は0件である。
