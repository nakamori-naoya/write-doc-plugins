# 執筆後の確認

**数えられる項目は数えて確かめる。** 「読みやすいか」で判定せず、文の数と字数を実際に見る。

- 各sectionの1文目に主張がある。
- 5文以上の段落がない。100字を超える文がない。
- 役の違う内容（課題／打ち手／求める判断など）が同じ段落・同じ文へ混ざっていない。
- 割ると決めた段落が、実際に別の段落として分かれている。
- 要約が役ごとの段落または箇条書き項目へ分かれている。
- 具体だけで終わらず、抽象へ戻して閉じている。
- 各文・段落は、明示された文脈だけで、主体・対象・時点または条件・述語の対応を一意に特定できる。読み手に暗黙の主語や目的語を推測させていない。
- Given/When/Thenや表は、各シナリオまたは各行だけで主体・対象・条件・結果の対応を一意に特定できる。
- 強調だけを拾い読みして筋が通る。
- 役が4つに収まり、装飾目的の強調がない。
- 出典には所在、原文引用、自分の判断が揃う。
- 未確認事項を確認済みのように書いていない。
- token、PII、machine固有pathを含めていない。
