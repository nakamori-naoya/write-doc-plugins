## BDD

<!-- この節は資料の末尾に置く。業務知識と技術処理の両方を扱うときは、業務知識の掲載順で業務由来のBDDを先に、技術的な処理のBDDを後に置く。
     各BDDは単独で読めるようにし、Whenは一つにする。年月日は「YYYY年M月D日」、時刻は「HH:MM」で書く。

     拒否のThenの直下に NOTE: Rule: と Reason: を置く。 -->

```gherkin
  And: <追加される行>
```
