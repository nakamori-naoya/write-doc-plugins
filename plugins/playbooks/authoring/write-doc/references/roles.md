# 意味上の役 — 3つの関心をつなぐ契約

**文章規律は強調の役、図の設計は図の3役を決め、媒体はそれらをタグ・記号・図形へ写す。**

両者は互いを知らない。**参照するのはこの役の名前だけ**である。役の名前を契約にしておくと、媒体が増えても規律を書き換えずに済み、規律を差し替えても媒体側は動かない。

## 強調の4役

`要点` / `キーワード` / `一言でいうと` / `要約項目` を契約名とする。役の付与は `writing-rules`、媒体表現への変換は `doc-render` が行う。この段取りは内容も書式も決めない。

## 図の3役

図を必須にするかは、上段が `requirements.figures` を boolean で解決し、図の工程が返した結果を `figures_required` と照合する。visual-guidanceへ必須判定を渡さない。

| 役 | 決定者 |
|---|---|
| **図の主張** | `visual-guidance` |
| **図の型** | `visual-guidance` |
| **図の内容** | `visual-guidance` |

図の題材と型は図の設計が判断し、媒体はこの3役を描画表現へ写す。上段は役の名前と、図を必須にするかだけをつなぐ。

## 構造の役

骨格、出典、コード注釈の役も、上段が意味を確定し `doc-render` が媒体表現へ写す。この資料ではタグや記号を再定義しない。
