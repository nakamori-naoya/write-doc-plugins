# 概念説明の見本（抜粋）

この見本は、概念説明の資料で判断が分かれやすい箇所だけを抜き出したものである。題材の値や言い回しは写さず、どこで何を判断したかを見る。節の構成はテンプレートが持つ。

## 冒頭で、読み手が取り違えている点を言い切る

この題材では、画面に「仮押さえ」と出ても確定していないことを読み手が取り違えやすいので、冒頭をその違いの一文にした。取り違えが別のところにある題材なら、冒頭の一文もそこを言う。

> 会議室を選んだ後に「仮押さえ」と表示されても、予約はまだ確定していない。仮押さえは利用意思を確かめるための15分間の保留であり、確定予約は会議室の提供を約束した状態である。

## 定義より先に、分かれる場面で見せる

違いは定義の言葉よりも、結果が分かれる場面で伝わる。ここでは確定したかどうかで場面を二つに分けた。数値の境目がある題材では、ちょうどの時点の扱いも書く。

> 10時10分に確定した場合は、10時15分を過ぎても確定予約が残る。確定しなかった場合は、10時15分を過ぎると仮押さえが期限切れになり、利用枠を他の顧客へ再販売できる。

## 似た言葉と混ざる誤解を、一文で閉じる

「保留期限で消えない」を「取り消せない」と読む誤解が起きうるので、一文で閉じた。誤解が起きない題材では書かない。

> 「保留期限で消えない」ことは「取消不能」を意味しない。
