# 用語集

> これは [`glossary.md`](../templates/glossary.md) の記載例である。

この文書は、架空の会議室予約サービスRoomFlowを題材にした記載例であり、実在するサービスや運用を示すものではない。

RoomFlow 2.3.0の予約業務で使う語を定義する。予約者、開発者、問い合わせ対応者が、会議室の予約について話すときと文書を書くときに、同じ語を同じ意味で使うために引く。語の意味と、どの語を避けるかだけを扱う。予約がどう成立し、どう取り消されるかという業務上の決まりは[業務知識・コアドメインの記載例](domain-rule.example.md)、操作手順は[ハウツーガイドの記載例](how-to.example.md)にあり、ここでは繰り返さない。

## 利用枠

一つの会議室に対する、利用開始から利用終了までの半開時間帯である。会議室だけを指す語でも、日時だけを指す語でもなく、その二つの対を指す。半開なので、10:00から11:00までと11:00から12:00までは重ならない。

- **使う場面**: 予約同士が同じ会議室で重なるかを判断するとき
- **使わない語**: 「コマ」「スロット」「枠」は使わない。会議室を伴うかどうかが読み手ごとに変わり、重なり判定の会話で食い違うため

## 仮押さえ予約

顧客の利用意思を確認する間、利用枠を他の顧客へ販売しないでおく予約である。受け付けてから15分で期限が到来し、その前に確定されなければ期限切れ予約になる。利用意思が確認された後は確定予約と呼び、仮押さえ予約とは呼ばない。

- **使う場面**: 予約者が利用するかどうかを決める間、その利用枠を確保しておくとき
- **使わない語**: 「仮予約」「ホールド」「押さえ」は使わない。「仮予約」は確定前の予約全般と読まれ、期限が付くことが伝わらないため

## 確定予約

顧客の利用意思が確認され、RoomFlowが会議室の提供を約束した予約である。仮押さえ予約は含めない。利用開始前に取り消されるか、利用終了に達するまで、提供の責任が続く。

- **使う場面**: 顧客へ会議室の提供を約束済みかどうかを判断するとき
- **使わない語**: 「本予約」「予約確定」は使わない。「本予約」は仮押さえ予約との対でしか意味を持たず、取消や利用終了までの責任の続き方を含まないため

## 仮押さえ期限が到来した

仮押さえ予約が確定されないまま、受付から15分後の時刻に達した業務イベントである。人が予約を取り消した事実ではなく、期限管理担当が時刻の到来として成立させる。

- **使う場面**: 仮押さえ予約を期限切れ予約へ移し、利用枠を再び販売できる状態にするとき
- **使わない語**: 「タイムアウトした」「自動キャンセルされた」は使わない。「キャンセル」は人が取り消した操作を指す語として別に使っており、原因の違いが記録と問い合わせ対応で混ざるため
