# 図を媒体へ写す

**何をどの図にするかは、図の設計から受け取る。** ここは描き方だけ。

## 図の役を媒体へ写す

| 意味上の役 | HTML | Markdown |
|---|---|---|
| 図の主張 | 図の直前の1文＋`<figcaption>` | 図の直前の1文＋画像直後のキャプション |
| 図の型 | 配置・座標・図形の選択へ反映。型名そのものは表示しない | 外部 SVG の配置・図形へ反映。型名そのものは表示しない |
| 図の内容 | `<figure>` 内のインライン SVG | 外部 `.svg` を相対パスで参照 |

**図だけを置かない。** 図の主張を本文の1文として先に置き、図だけ拾い読みしても何を理解すべきか分かるようにする。

## HTML 出力のとき

**インライン SVG で書く。** 外部ファイルにすると、単体で配れなくなる。

- キャンバス全面を覆う背景 `<rect fill="var(--bg)">` を必ず置く。無いと閲覧側のテーマで読めなくなる。
- `viewBox="0 0 W H"` と `width`/`height` を同値で明示する。横幅 1280 を基準にする。
- 色は presentation 属性（`fill` / `stroke`）で直接指定し、値にはHTMLシェルのCSS変数（`var(--bg)` / `var(--ink)` / `var(--muted)` / `var(--line)` / `var(--panel)` / `var(--accent)` / `var(--accent2)` / `var(--imp)`）を使う。**ライト固定のHEX色を埋め込まない。すべての図形に色を書く。**
- `<text>` は自動改行しない。改行は座標を分けて別要素にする。
- `<` `>` `&` は `&lt;` `&gt;` `&amp;` にする。
- 図中の文言は常体・体言止めにする。

配色は本文の CSS 変数と揃える（`reference/output-html.md`）。


## Markdown 出力のとき

外部の `.svg` を作って `![alt](相対パス)` で参照する。インライン SVG は多くのビューアで描画されない。

図の代わりに**表**で足りるならそちらを選ぶ。Markdown では表のほうが確実に読める。
